# Stage2 tune 可复用性能模型设计草稿

状态：设计讨论，尚未实现。本文记录已确认要求和待决策项，不作为当前程序行为规范。现有实现见 [Auto B2/tune](architecture/AUTO_B2.md)。

## 已确认要求

- 取消 tune 性能选型的 B1 精确匹配要求。用户要求使用本项目设计的模型，不依赖 Prime95 关于 B1 的经验模型；具体成本与收益模型仍待确定。
- 性能条件支持按项忽略：gpu、driver、cuda、backend、memory、environment。默认忽略 gpu、driver、cuda、backend、environment，保留 memory 匹配。算法支持、目标数一致性、承载整除关系及实时显存准入按当前请求检查。
- 支持短校准以修正当前设备和计算路径的成本估计，覆盖少量 NTT、归约及点运算，同一次队列运行复用结果。缺少所需 NTT 或其他必须性能数据时执行短校准；输出使用正式 tune 文件格式，保存少量符合该格式的汇总条目，供后续复用。默认测量预算10秒，可通过INI调整；包含预热和测量，首次CUDA初始化另计。到达预算保存已完成的有效条目，剩余成本由模型估算，并区分实测与估算。兼容性差异下的具体触发规则待确定。
- 自动短校准在启动时检查必要性：不存在合适 tune 文件，或当前 worktodo 任务范围完全没有可复用校准覆盖时触发；已有适用覆盖则复用。本次运行各曲线复用校准结果，可配置关闭。覆盖按实际计算形状、执行路径和允许忽略的条件判断，不要求 B1 或目标位宽精确匹配；部分覆盖时可复用已有模型并按已批准规则估算缺项，具体覆盖判据仍待设计。缺失必须的 NTT/组件数据继续按前述规则补校准。
- 队列根据 worktodo 的数表达式、已知因子与 save 中的实际 N 检查一致性；从梅森任务取得承载指数，验证实际整除关系后，将承载加入成本估算与选择。合法性与性能优劣分别判断。
- 位宽预设 a:b 生成 b、2b、…、ab，再额外加入 512 bits。基准数构造及目标位宽附近的实际取值策略待确定。
- 运行时取消实际 N 位宽精确匹配，允许跨基准点估算；模型使用实际 limb 数、NTT 长度与批量，在相邻位宽基准间校准参数。普通模数和梅森承载分别估算；承载使用指数 p 对应的算术位宽。基准范围外的估算策略待确定。
- D 从现有目录均匀选取指定数量，不再取前若干项。
- 原表的“B1范围”为笔误，实际为 B2 范围。B2 默认上限 U=2.6×10¹²；a:b 生成 a 个点，按倍率 b 向下覆盖，B2_i=U/b^(a−1−i)，i=0…a−1。边界取整、显式范围覆盖与不可执行组合的处理待确定。
- TOML 保留每个候选的最终汇总耗时及必要模型参数，不只保存获胜 D/承载。逐次采样及运行记录不进入性能文件。
- 多次 tune 更新时，按正式重复的耗时中位数比较；新中位数严格更低时替换，相等或更慢时保留原项。最终汇总保存重复次数和 MAD，不保存逐次采样数组。
- 上述替换比较仅在同一设备、后端及测量条件内进行。不同条件保留各自的最终摘要，运行时允许跨条件复用并校准；配置中的忽略项影响复用筛选，不使不同条件的原始秒数直接参与最快值覆盖。条件键的具体字段仍待设计。
- Stage1 成本支持用户提供的 CSV 表格，缺项允许推断；按 B1 和频率的近似线性缩放、位宽的近似平方复杂度构建初始模型。允许缺失位宽及测量范围外的外推，区分实测、插值与外推；跨 TPI 档位使用实际容器位宽和 TPI，并通过短校准修正，具体修正方法仍待设计。具体分段及批量处理待确定；用户提供的数值不冒充本仓库新测量证据。
- Auto B2 收益采用成功概率除以总流程耗时，保留连续生成并处理新曲线的目标，并计入实际 B1 对应的 Stage1 成本。成功概率参考 GMP-ECM 光滑性模型及本仓库 `tools/ecm_prob` 的复刻/改写；目标因子大小默认按 B1 推荐，可配置覆盖。概率模型中的实际 B1 不要求等于 tune 的采样 B1；推荐映射和概率接口仍待核对。
- tune 默认生成完整等级网格，以组件实测和少量完整曲线点校准，未实测组合由模型估算并明确标记。独立校验点的耗时预测相对误差超过8%时逐步增加完整曲线测量点，门限可配置；误差为绝对预测差除以实测中位数。优先在偏差所在计算形状区域补点，不默认逐组合穷举运行；补点选择及时间预算仍待确认。测量摘要与估算条目分别识别，估算秒数不能覆盖原有实测最快摘要。
- TOML 可记录数据来源（实测、模型、校准等）、校准/校验误差及其适用范围。误差来自已完成的独立校验，未经校验的条目不能记录为零误差或宣称通过；区分训练拟合误差和独立校验误差。不保存逐次采样或运行历史。
- tune ecm 总预算默认30分钟，可配置；预算到达后不发起新测量，保存已完成的有效结果，允许已开始的测量结束，因此预算不是硬超时。未达到8%误差门限的区域标记未收敛。此预算与默认10秒的短校准预算分别管理。
- 多次 tune 复用之前成果并逐步提高精度：保留有效实测摘要，优先补全缺项、未校验及误差超限区域，根据累计摘要重新校准模型。实测最快值的替换规则继续适用；模型更新按新增证据与精度处理，不能简单以模型预测秒数更低作为替换依据。具体补测调度仍待设计。
- 生产 Auto B2 允许尚未收敛或未经完整校验的模型参与选型；成本使用不确定性余量，输出明确注明估算/未收敛状态，不宣称精度已达标。当前任务仍独立检查算术支持、目标一致性、承载整除和实时显存准入。余量的计算方法仍待设计。
- 默认 memory 匹配按执行路径（如 fold 驻留、NTT 分块）判断，不要求 arena_mb/fold_mb 等预算数值完全相等；每个候选按当前预算重规划并核对路径与实时显存准入。
- tune 的主要目标是在当前内存限制下选择更优的 D/P，降低完整 Stage2 成本，尽可能延后昂贵 NTT 形状的交叉点并平衡大规模运算效率下降。P=φ(D)/2，不能作为独立于 D 的任意参数；NTT 长度跳变、归约和内存路径变化分别计入成本，复杂度与性能结论需按实测区分。
- fold/frontier 回退路径纳入候选并与驻留路径分别建模；显存占用接近边界时，优先比较边界两侧的可执行形状并补测。计入临时分配、缓存驱逐及传输成本，运行时重新检查当前预算、显存快照与联合生命周期；不得把各模块峰值之和当作进程峰值。
- Auto B2 默认搜索 B1<B2≤2.6×10¹²，可通过配置扩展范围；tune 网格提供校准锚点而不强制限定搜索范围，未测 B2 可用模型估算，超出模型校验范围时标记外推并计入不确定性余量。显式上下界、实际算术支持和当前显存准入仍约束候选。

## 用户提供的 Stage1 成本

条件：4060 Laptop、2000 MHz、B1=110×10⁶，单位为程序输出的 s/curves。TPI8使用768曲线，TPI16使用384曲线，统一提交2 blocks/SM。当前源的TPB=128，与C=2·SM·TPB/TPI及上述批次相符；这里的提交块数不等于所有位宽下的同时驻留块数。

- TPI8：1792 bits → 9.5 s/curve；1280、1536、2048缺少耗时。
- TPI16：2560 → 19.6；3072 → 26.6；5632 → 66.8；6144 → 76.3；6656 → 90.0；7168 → 105.7；8192 → 140.4，单位均为s/curve。3584、4096、4608、5120、7680缺少耗时。
- 本表为用户提供的成本参考；算法/指数模式、核验信息及其他TPI数据未给出，不据此声明完整Stage1计时或独立末点验证已通过。

## 等级预设

记位宽为 w:Δ，B2 为 a:r，另加 512-bit 基准；D 为均匀选取数量，重复为正式测量轮数。

- level 1：位宽 3:4096；D=4；B2 3:10；重复=2。
- level 2：位宽 4:3072；D=6；B2 3:10；重复=2。
- level 3：位宽 5:2048；D=8；B2 4:10；重复=2。
- level 4：位宽 5:2048；D=10；B2 4:10；重复=2。
- level 5：位宽 5:2048；D=10；B2 6:5；重复=3。
- level 6：位宽 8:1536；D=12；B2 6:5；重复=3。
- level 7：位宽 8:1536；D=12；B2 6:5；重复=3。
- level 8：位宽 10:1024；D=12；B2 8:5；重复=3。
- level 9：位宽 15:1024；D=12；B2 8:5；重复=5。
- level 10：位宽 15:1024；D=14；B2 8:5；重复=5。

## 概率工具核对

- `tools/ecm_prob/rho.py` 的 `prob`、`stage1_prob`、`stage_prob` 分别提供完整概率、第一阶段概率及指定有效除子的两阶段概率。概率中的 N 是目标素因子规模，不能传入待分解余因子的总位宽。
- `tools/ecm_prob/model.py` 区分 GMP-ECM 常数与小因子样本拟合的有效除子，并提供 `GMP_BIT_TABLE` 和推荐 B1 的回归式；这些可作为默认目标因子大小推荐的依据，具体映射与边界尚未定稿。
- 生产实现需要在本机可执行文件内提供概率核心，Python 工具作为参考与核对入口；避免发布程序依赖 Python 或 `tools/ecm_prob/out` 的经验测量文件。概率的有效范围、数值稳定性和曲线族参数仍需核对。
- 当前 poly 路径的概率模型只计入实际支持的 Stage2 覆盖；不能因为参考工具支持 Brent–Suyama 项而默认计入对应收益。
- 全组合完整测量成本需要控制：level 10 含额外 512-bit 基准后有 16×14×8×5=8960 次普通模数正式重复，尚未计入预热和承载路径。组件测量、完整曲线锚点及估算覆盖的边界待确认。
