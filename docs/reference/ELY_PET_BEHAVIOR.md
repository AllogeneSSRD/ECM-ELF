# ELYTerminal 桌宠行为分析

参考本机 `.refactor/ELYTerminal` 提交 `c5f6ea789d8301ab558ede329cb66ac8788343cb`，分析对象为 `src/pet.rs`、`src/pet/look.rs`、`src/pet/look/curves.rs` 与 `src/pet/rig.rs`。这是上游代码分析，不代表ECM-ELF已实现全部动作。上游MIT许可适用；本仓库现有造型资源固定版本及版权另见 `assets/gui_v2/CLASSIC-ELY-NOTICE.md`。

## 结构与输入

上游没有随机概率行为引擎。`look.rs::mood` 将会话标记合成为五种情绪，优先级为 Waiting > Error > Working > Done > Calm。`look.rs::pose` 根据情绪持续时间、显示时间与距上次点击时间生成动作；`pet.rs::Pet::pose` 在动作或情绪变化、点击时保存上一姿态，通过0.3秒缓动过渡。

情绪与动作分开：情绪有五种，动作有 Calm、Doze、Cheer、Work、Wait、Fret、Wink。`Pose` 同时携带头部浮动、倾斜、发束摆动、呆毛角度、视线、左右眼开合、嘴形、手部与标记的变换。`rig.rs` 把这些参数应用到各矢量部件。窗口层只管理事件、时间、定位和绘制；动作层不访问窗口。

## 平静与微动作

- `look.rs::idle` 给每个动作叠加基础活动：正弦浮动、相位错开的发束与呆毛摆动、眨眼、进入动作时的眼睛张开与嘴形弹出。
- 平静浮动周期2.6秒、参数幅度4个造型单位；发束摆动周期5.2秒、幅度2.2度，呆毛基础摆幅4度。造型坐标经rig缩放，不能把这些参数直接称为屏幕像素。
- 平静动作以20秒为一轮：9–10.2秒看向一侧，16–17.2秒看向另一侧，头部随视线倾斜；12.4秒触发一次呆毛轻甩。
- `curves.rs::blink` 按3.4、4.6、0.32、5.2、2.8、4.1秒的间隔循环，整轮20.42秒。0.32秒短间隔形成双眨眼。每次70ms合眼、30ms停留、120ms张眼；不是每帧抽概率。
- `curves.rs::wiggle` 在0.7秒内依次通过0、−16、11、−6、0度，用平滑插值收尾。

因此原版的“自然”来自不同周期、相位偏移、短暂动作和缓动组合；时间表本身是确定性的。

## 任务与交互

- 工作：2秒轻浮、2.25秒扫视文字行，手指在3秒周期的前1.8秒交替轻敲。
- 等待：更快的1.6秒浮动、惊讶表情、摇动感叹号，每2.6秒安排两次跳动。
- 错误：皱眉、摇头和下落汗滴；首次摇动后，每4.5秒补一次较小摇动。
- 完成：庆祝4秒，笑眼、跳动和闪光；之后回到平静动作。
- 点击：眨单眼、微笑、脸红、小跳、甩呆毛与上浮爱心，持续1.5秒。显示时另有0.6秒从边缘探出的入场动作。

## 睡眠条件

仅Calm和庆祝结束的Done可以自然进入Doze。平静情绪持续满300秒，且点击后的重新计时也已满300秒，才睡觉；工作、等待、错误不会自动睡。情绪变化会重置情绪持续时间，点击会重新给予平静状态五分钟清醒时间。

入睡时约0.6秒合眼、0.8秒低头，呆毛下垂；之后4.2秒呼吸浮动、8.4秒轻微倾头。两个Z标记按2.4秒周期错相漂浮和淡出。点击睡眠中的角色会睁开另一只眼并播放抚摸动作。

## 适配边界

ECM-ELF早期离线生成器仅从固定rig提取造型，生成七状态八帧图集；没有移植上游look与curves的完整姿态计算。全图集按150ms轮播是移植层的行为，不是原仓库的算法。

若需要更安静、随机穿插的表现，可沿用“情绪/生命周期 + 微动作调度 + 独立姿态/绘制”的分层方式：睡眠阈值和点击唤醒保持确定性；只对眨眼、呆毛的下次触发间隔做受限随机，并设置动作持续时间和间隔。平移和缓动按单调时间计算，避免帧率改变动作速度。图集适配只能近似上游分层矢量动作，完整眼球、双手、标记和姿态融合需要额外图层或资源支持。

上游`pet.rs::render`每次请求下一动画帧。这属于GPUI呈现策略，不能直接据此推导ImGui桌宠所需刷新率或资源消耗；两种实现需要分别实测。
