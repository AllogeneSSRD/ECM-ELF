# Stage2 G 乘积树的分块空位布局

## 数学条件

设本批有 n 个线性多项式 `g_i(X)=Z_i X-X_i`，系数位于任意交换环 `R=Z/NZ`。乘积只依赖全部真实叶及其重数，和二叉树的结合次序无关。空叶表示常数 1，次数为 0；它不能替换成根为零的线性多项式，也不能计入实际覆盖点数。

因此，调整只消费根的 G 树布局不需要扩大 B2，也不需要任何 Z_i 可逆的额外假设。非单位和零最高系数仍保留原有多项式。各次乘法归约为同一规范系数后，根的全部系数应与原布局逐字一致。F 树还服务有序下降；本方法不能在未处理叶映射的情况下直接套用到 F 树。

## 分块布局

令 q 为不小于 n 的最小二次幂。对 n>0，选取

`T=min(q,max(16,q/128))`，`S=q/T`，`M=ceil(n/T)`。

T 是二次幂，S≤128。将真实叶按原顺序分成 M 个块，每块 T 叶，末块允许不足 T。第 k 块放到第 `floor(k*S/M)` 个块槽，块内仍连续存储。真实叶 i 的树槽为

`slot(i)=floor(floor(i/T)*S/M)*T+(i mod T)`。

树槽严格递增，因此设备上的线性叶数组可保持原密集顺序；节点偏移由真实次数的前缀和得到，无需复制、散排或额外填入常数 1 的系数。低于块大小的各层仍是原来的密集子树；较高层的有效块被分散到两侧，减少根部的极端输入不平衡。

例：n=17280，q=32768，T=256，M=68。原左侧连续布局的根两侧次数为 16384/896，新布局为 8704/8576；最大的根乘法输入由 16385 个系数降到 8705 个。n=51840 时两侧从 32768/19072 改为 26112/25728。NTT 长度是否下降还取决于系数位宽、packing 和后端长度选择，不能只据次数比例推导耗时。

## 工作量与空间

真实叶仍为 n，非空逻辑乘法仍为 n−1。空子树通过复制非空子节点处理；复制次数和每层分组形状可能改变，必须包含在实际性能测量中。

当 q>1 时，T 是偶数，因此首个父层的非空节点数仍为 `ceil(n/2)`，该层存储 `(n+ceil(n/2))*W` 个 64-bit word。之后各层的次数和保持 n，非空节点数只减少，故首父层仍是第二个 raw 缓冲区的最大容量；首叶层为 `2*n*W`。该结论只涉及两块 raw 系数缓冲区，不是进程显存峰值。元数据容量仍由原 q 决定，NTT 请求形状和缓存则须按新树重新计算。

压缩规划可先枚举块内原始密集分组，再显式枚举至多 128 个块槽的上层树，无需物化全部 q 个叶节点。每层按 `(min_operand,max_operand)` 排序聚合，应与设备的实际请求及有序签名完全一致。
