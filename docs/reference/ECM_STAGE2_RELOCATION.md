# 多项式 Stage2 relocation：覆盖证明与因子恢复

固定数学与源码研究资料。Prime95 31.6b1 的具体 B2_start、缺失素数和完整批次规则见 [Prime95 Poly Stage2 §4](PRIME95_STAGE2.md#4-b2-上扩完整-g-多项式与-relocation)；基础相遇判据见 [Stage2 数学](ECM_STAGE2_MATH.md)。本页不声明任何生产后端已实现 relocation。GPU 适配范围和成本分析保存在[开发草稿](../development/EDWARDS_GPU_STAGE2_OPTIMIZATION_DRAFT.md#相同-b2-下-relocation-的可行性与成本)。

## 1. 从低区间移到高区间

本页保留离线研究的条件、证明与证据；生产功能及随后完成的 GPU 验证另见 [Stage2 可选 relocation](../architecture/STAGE2.md#可选-relocation) 和 [性能数据](../performance/EDWARDS_STAGE2.md)，不以本页的旧研究条件描述当前实现状态。

设 Q 是 Stage1 后的点，D 为偶数，J={1≤j≤D/2:gcd(j,D)=1}，P=φ(D)/2。若某个待找因子模数上的 Q 被 [q] 消去，任何 [m^a q] 也消去 Q。只要 gcd(m,D)=1，且 q∤D，移位后的 t=m^a q 仍可写成 iD±j，j∈J。

因此，若只要求覆盖素数 q∈(B1,B2]，可选择 L≤B2/m，将每个较小 q 反复乘 m，直到第一次达到 L。由于前一步小于 L，新的 t<mL≤B2；q≥L 则无需移位。选 m 为不整除 D 的最小素数，得到最大的这种简单区间缩短，忽略取整的 giant 点节省比例约为 1/m。若 B1 已经更大，还可按既有完成范围约束起点。

密集的 G 多项式自然包含对应复合倍数的相遇项，不必为每个 q 建表或在 GPU 上逐个计算 m^a q。m 的角色是覆盖证明和区间规划参数。它不是待分解整数的因子，也不是 Stage1 的额外标量。

这项证明针对 [q]Q=O 的 Stage2 条件，不把“群阶含 q”误写成“[q] 一定消去 Q”；需要 Stage1 已去除其他所需部分。

## 2. 保留既有 giant 网格的保守后缀

只按请求 B2 缩短区间，未必保持另一个执行器原有的附带覆盖。例如某引擎原来生成 i=1,…,I，I=⌊B2/D⌋+2，则它还可能通过 guard 点发现请求 B2 以外的残余阶。要求保持原有因子行为时，应先研究这个完整离散网格，而非直接以 Prime95 的 nominal B2_start/B2_end 替换它。

对原网格定义：

\[
m=\min\{\ell:\ell\text{ 为素数},\ell\nmid D\},\qquad
A=\max(1,\lfloor I/m\rfloor),\qquad
I_{suffix}=I-A+1.
\]

保留 i=A,…,I，终点和请求 B2 都不变。此处 A 是保守起点，不声称最少点数或全局最优；A=1 时不省点。

### 2.1 普通相遇项

旧相遇项对应的正整数 t=iD±j 满足 t≤U=ID+D/2−1，且 gcd(t,D)=1。在一个非奇异模素数曲线上，x([iD]Q)=x([j]Q) 蕴含 [t]Q=O，对应其中一个符号。

若 t 的最近 D 中心仍小于 A，反复乘 m，直到 t' 的中心第一次达到 A。中心小于 A 的前一步满足 t_prev≤AD−D/2−1，因此 A>1 时：

\[
t'=m t_{prev}\le mAD-mD/2-m\le ID-mD/2-m<U.
\]

这里使用 mA≤I。又因 gcd(t',D)=1，新的中心属于 [A,I]，余数仍在 ±J 中，并有 [t']Q=O。所以原先每个相遇见证都能移到保留后缀。反向蕴含直接来自“后缀是旧网格的子集”。结论是相遇乘积在模各个素因子上的零/非零支持相同，包含原先的复合倍数和终端 guard 覆盖，不仅限于请求范围内的素数。

### 2.2 无穷远点

giant 点自身的 Z 非单位也可能提供因子。若 [iD]Q=O，对 i<A 反复乘 m，直到 i'≥A；第一次越过 A 的 i'≤m(A−1)≤I，故该退化同样在后缀内出现。baby 点没有改变。小素数补偿及被 D 吸收的素数仍沿用原有完整路径，不能因有 relocation 而删除。

这证明的是合法有限域曲线上的覆盖关系。它不能替代合数模环中的逆元分类、非单位回退、差分链退化处理或算术核验；使用承载 M 时，判断对象仍是目标 N 的素因子。

## 3. 相同零支持不等于相同叶和可提取因子

移位会改变 baby 剩余类：m^a(iD±j) 一般对应另一个 j'，所以最终叶值甚至哪些 baby 叶为零都会变化。例：D=10、I=63、m=3、A=21，残余点阶71的旧见证71=7D+1被移成213=21D+3。旧命中叶集合为{1,3}，新集合为{3}。不能把跨区间叶指纹相等用作验收条件。

更重要的是，不同素因子可能被合并到同一乘积块。若检测器只接受 1<gcd(product,N)<N，而跳过 gcd=N，覆盖等价不能保证它提取到相同因子。下例用精确有限域椭圆曲线计算证明这一点：

- N=1,693,835,369,273=1,186,519×1,427,567；两个因子均用试除确认是素数。
- 曲线可写成 Edwards d=−1、Montgomery A=0/B=2，或 Weierstrass y²=x³+4x。模两个因子的 Stage1 末点阶分别为29663和29741，均经素数性及直接点乘验证；也构造了 B1=20、标量48LCM 的有效 Stage1 原点。
- 固定 D=2310、P=240、B2=1,175,790，旧 I=511；取 m=13、A=39。以64个 baby 叶为一块。
- 旧四个块的 GCD 为 **[N,1186519,N,1]**；后缀四个块为 **[N,1,N,1]**。只接受真因子块的检测器，旧路径得到1186519，后缀路径得不到因子。

该例没有 baby/giant 无穷远点，也无小素数补偿可掩盖这个差别。它是有效椭圆曲线上的离线精确算术反例，未使用 GPU，也不是本仓库 Atkin–Morain sigma 构造的实测样本。它否定的是“仅改起点即可保持最终因子行为”的推论，不否定 relocation 的覆盖证明。

可用的恢复策略包括：gcd=N 时继续拆分叶和 giant 见证乘积；或检测到任何非平凡 GCD/非单位后重放原有网格，用原路径完成因子提取。若还要求严格保持原路径的因子集合和最小 B1/B2 行为，重放原路径比直接发布不同分组的 GCD 更容易建立兼容性。重放前不能发布 NF 或推进曲线完成状态。

## 4. 已完成的离线核对与边界

证据目录为 `data/experiments/stage2_relocation_feasibility_20261017/`，由 Git 忽略，所有分析文件保留：

- `analyze.py` / `analysis.json`：8种 D、80组区间，逐个映射361086个相遇见证及4088个giant无穷远见证；16384个循环点阶条件的整体相遇与无穷远覆盖一致，其中1834个条件的 baby 命中集合发生改变。
- 同一分析包含12条小有限域曲线：4条完整 Edwards 模型及8条 Suyama PARAM0 曲线，共144组区间对照；Edwards 与独立 Weierstrass 点运算之间核对5121个映射。Edwards 模型不冒充 Atkin–Morain 参数化。
- `gcd_collision_probe.py` / `gcd_collision.json`：上述合数 N、曲线、点阶、48LCM 原点、逐叶积与块 GCD 反例。指纹覆盖分析脚本、辅助脚本和研究时的 GPU 主源文件。

这些核对支持数学推导和反例，不验证生产 GPU 的偏移索引、Γ、承载投影、因子恢复或性能。源码版本与输入指纹保存在 JSON，不能把这项离线研究当作已完成的 GPU 功能或性能结论。
