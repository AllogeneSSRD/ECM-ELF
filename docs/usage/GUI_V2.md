# GUI v2

GUI v2 是独立的 Windows / C++ / Dear ImGui 前端，当前候选版本0.49.1，默认使用DX11，Vulkan仅保留为显式选择的诊断后端。两种后端共用同一套现代布局、控件、图表、语言与宠物。原GUI的源码、默认值、二进制和构建入口保留。阶段证据与限制见 [实施草稿](../development/GUI_MODERNIZATION_DRAFT.md) 和 [离线 HTML](../web/gui-v2-vulkan-plan-20261021.html)。

## 构建与启动

运行 `tools\build\build_gui_v2.bat`，默认生成 `build_gui_v2_local/ecm_gui_v2.exe`。测试入口 `tools/build/test/build_gui_v2.ps1 -BuildDir <独立目录> -TestHelpers`；helper 不进入默认交付目标。根开关 `ECM_BUILD_GUI_V2` 默认 OFF，与旧 GUI 独立。需要 MSVC/CMake 及仓库固定源码，构建无需开发 Vulkan SDK、CUDA 或浏览器运行时。

运行要求Windows 10 1903+ / Windows 11 x64、匹配的Microsoft Visual C++ x64 runtime和DX11驱动；硬件不支持时尝试系统WARP。默认启动不初始化Vulkan、不加载Vulkan loader，也不需要Vulkan SDK。构建仍携带可选后端的固定头文件与Volk。

未传`--config`时，自动查找并载入`ecm_gui_v2.exe`同目录的`ecm.toml`，不受快捷方式“起始位置”或当前工作目录影响。不存在时保持GUI打开并提示选择工作流；存在但内容有误时显示加载错误。显式`--config`优先，指定文件失效时不会退回旁边的另一份配置。工作流路径确定后再选择对应的UI侧车，自动发现和显式打开同一配置使用相同身份。按该配置的`workers.N.autostart`执行自动启动。

常用参数：

- `--config <工作流.toml>`：打开已有业务配置；设置中也可选择。autostart 经过能力与拥有权检查后执行。
- `--ui-state <侧车.toml>`：默认 `%LOCALAPPDATA%/ECM-ELF/gui-v2/<配置身份>.toml`；按启动配置身份隔离，与业务文件分离，非法侧车保留并禁止覆盖。
- `--theme dark|light`、`--language en|zh`、`--ui-scale 1|1.25|1.5|2`：初始外观；设置可选自动 DPI。
- `--pet` / `--no-pet`、`--pet-static`：宠物及动画覆盖，默认关闭。
- `--pet-skin classic|miss_pink_elf|herrscher_of_human_ego|hi_love_elf`：初始ELY皮肤覆盖；配合`--pet`启用，默认保持Classic ELY。
- `--no-nvml`：关闭可选的 500ms 后台 GPU 监控。
- `--renderer dx11|vulkan`：默认dx11；仅显式选择vulkan时要求系统Vulkan 1.1 loader、graphics/present与swapchain驱动。
- `--single-viewport`：保持所有 ImGui 面板在主窗口内，当前默认模式。
- `--multi-viewport`：显式启用可移出主窗口的原生独立面板；设置中也可启用，重启生效。
- `--renderer vulkan --trace-render --diagnostics <文件>`：可选记录Vulkan等待/提交/呈现的进入和返回、单调时钟与UTC对应；逐调用写盘有额外开销，不用于性能门禁。
- `--diagnostics <文件>`、`--version`：诊断路径与独立前端版本。

设置是可滚动的单页流式布局，外观、导航/布局、工作流与计算编辑依次排列；无外观/布局/工作流子页切换。可直接点击主题、语言和 DPI 比例标签，设置平滑滚动、操作 Toast、宠物及动画；菜单中的语言也即时生效。中文字体不可用时回退英文，并提示原因。设置中的 worker 路径、数量为 v2 偏好；数量 0 跟随工作流。相对程序路径优先工作流目录，其次前端目录。外观保存不改旧 `[gui]`。计算设置须显式保存，复核文件指纹并保留未改行/注释；外部修改须重载。运行中禁用编辑，未保存编辑禁止启动。工作流设置支持按配置键或英中说明搜索、按共用 / Stage1 / Stage2 / Worker 筛选；显示匹配项与空状态、准确配置节的类型和范围说明。布尔与 0/1 开关使用复选框，其他数值保留精确文本输入。暂存、保存和重载分开；worker 程序可用文件选择器指定。

系统标题栏默认显示；可在“视图 → 系统标题栏”或“设置 → 显示系统标题栏”即时切换。隐藏时通过顶部空白区域拖动窗口，右上角保留最小化、最大化/还原和关闭按钮，窗口边缘仍可缩放；关闭仍走原有安全停止流程。选择保存在独立侧车的`window.title_bar`，正常退出或保存界面偏好后恢复，旧侧车缺少此项时保持显示。

## 导航与布局

导航项右键选择“移到右侧工具栏”，或将其拖到导航底部的“工具 >”按钮。移入的页面从左侧导航移除，在右侧以点击标签切换；工具可通过“移回导航”按钮、右键菜单，或拖到左下“< 导航”按钮返回。至少保留一个中央页面，中央与右侧不会同时编辑同一页。窄窗口保留可滚动的右侧工具页，导航始终保留页面名称，窄侧栏可横向滚动并显示完整提示；可在“视图”菜单隐藏工具栏，点击导航的工具按钮恢复。

设置中的“导航与右侧工具栏”区域也可选择页面位置、恢复默认布局。拖动窗口标题可以在主窗口内重新停靠、调整分栏或浮动；切页回到顶部，避免继承上一页滚动位置隐藏信息。

默认使用DX11，首次布局将面板保留在主窗口内部；在“允许面板移到应用窗口外（重启生效）”或命令行显式启用后，可跨显示器浮动。RTX4070 Ti双屏环境的一轮DX11内部/独立面板图表拖动、缩放和最小化恢复检查通过，用户确认该轮未观察到冻结；不能据一次短测承诺长期稳定性。

可选Vulkan路径尚有未解决的桌面画面冻结：外屏与内屏同时停止更新、鼠标仍可移动、时钟停走，恢复后输入体现效果；曾捕获547ms和1000ms的present等待，根因未确定。该路径未通过冻结验收，已停止在受影响桌面反复拖动复测。CPU帧耗时或API验证均不能替代实际桌面刷新判断；DX11路径不据此宣称Vulkan已修复。

界面偏好文件保存页面位置、右侧选中项、显示状态和 ImGui 布局；正常退出保存，也可显式“保存界面偏好 / 保存布局”。计算设置与原 GUI 配置独立。旧侧车缺少新增字段时沿用默认值；非法侧车继续保留原文件并禁止覆盖。

## 队列、页面与宠物

即将执行的计算worker须支持队列协议：`--gui-queue-protocol`返回`ECM_QUEUE_OWNER=1`。纯Stage2任务不要求未使用的Stage1同时升级，反之亦然；自动切换阶段时，在下一套引擎启动前检查其协议，不支持则停留在已停止状态并提示具体路径，GUI继续工作。协议查询只确认worker声明支持的版本；实际互斥由运行期间持有的文件锁完成，防止重复计算同一分区和并发争用检查点/完成记录。共用入口的进程级文件区间锁覆盖 worker 生命周期，同一队列的相同分区拒绝重复运行，不同分区可并行；全队列与各分区互斥。崩溃由系统释放锁，持久锁文件不能手工删除绕过占用。原 GUI 必须指向更新 worker 才能参与保护；任意旧计算二进制不遵守新锁，v2 会拒绝启动。算法、曲线、param、sigma 及工作流格式不变。

任务表按操作、Worker、状态、设备/引擎、任务进度、每曲线耗时、ETA、完成/命中组织八列；单个worker的圆角启停按钮位于首列，表格上方保留全部启动/安全停止。设备/引擎在原有列宽内单行显示，如`GPU0 / S1`、`CPU / S2`，完整引擎/设备/曲线信息与重复GPU提示可悬停查看。状态使用色标，文字和按钮保留单元格内外留白。任务摘要独占下一整行，以不透明背景覆盖列网格；Stage2附加阶段、当前曲线、批次、B1/B2及已知构造身份，Edwards不显示param。进度保留完成/总曲线数与百分比，恢复状态明确标注；表格ETA只显示秒数，如`150 s`。未取得耗时样本时显示`--`，不伪造零耗时和零ETA。长表固定表头，窄区域可滚动，少量行按内容收紧高度；停止过程中禁用重复操作。

日志提供“程序”和每个Worker的独立页签。任务表选择与日志/检查区联动；页签显示当前任务、进度、每曲线耗时与ETA，ETA同时显示秒数和约化时间，如`150 s (2 m 30 s)`。Stage2用单行显示已解析的`B1=…  B2=…  S=… bits  D=…  P=…`，缺失数据为`--`。速度图使用各worker已有的每曲线耗时历史，横轴为采样序号，悬停显示秒/曲线；宽区域与正文并排，窄区域上下排列；面板较矮时通过工具行的“速度图”按钮展开，当前读数保留在摘要，优先显示日志正文，不额外采集数据。工具行提供日志目录入口，空间允许时显示文件名，完整路径可悬停查看。各Worker的原始输出、跟随及滚动位置在会话内独立；既有侧车`ui.raw_log`/`ui.follow_log`记录最后一次选择，作为新页签及下次启动的默认值。开启跟随时停靠在底部；手动向上翻阅不会被强制拉回，返回底部后继续跟随。日志正文行间距为2逻辑单位，时间戳弱化，检查点/队列信息、Stage1、Stage2、成功/因子、警告、错误分别使用主题语义色；只绘制可见行，颜色同时适配明暗主题。原始输出的进度行可附加约化ETA，磁盘日志和worker输出字节不改写。

工作台/检查区区分 Stage2 任务曲线进度与阶段/批次，保留 worker 版本、命令、Prime95 提示、事件/原始日志和安全停止。关闭日志或切页仍推进 Controller。结果支持 F/NF、阶段、来源与搜索，复制原始 JSON/checksum；筛选或文件更新清理失效选择。生成器按目标 worker 分区，输入或选项变化使预览失效，追加前复核文件并锁定队列；CPU 拒绝不支持组合。

概率页分为“参数”和“图表与快照”；显式计算后转到图表视图。概率输入、摘要、图表和悬停以0–100%显示，B1/B2、曲线数与范围等输入去除无意义小数；D_eff、比率及非整数解保留有效精度。模型与CSV概率仍使用0–1。概率正反算、图表、CSV 对应同一输入快照；参数修改后提示重新计算，已有图表和 CSV 保留其原快照。挠群阶 T 不等于 D_eff。Edwards Z2xZ8 的已有 Stage1 经验代表值为 26.4081（B1=256、15–25 bit 点口径）；按 Edwards/Suyama 相对收益归一到 GMP 基线约 29.0，作为联合模型启发预设，未经直接 Stage2 标定。可选择经验口径或自定义，不把 16 当完整 Edwards 预设。数学模型本身和旧概率页不改。依据见 [参数化参考](../reference/ECM_PARAMETERIZATIONS.md) 与 `tools/ecm_prob/README.md`。

常用筛选使用点击标签；滚轮短暂提升刷新频率以平滑滚动，静止恢复 10Hz。Toast 不抢焦点；启动、安全停止、配置/生成器反馈保留详细日志。GPU 未知样本不伪造零值，容量单位为MiB，另有百分比、MHz、W与摄氏度。GPU核心频率、显存频率分项显示并提供可展开趋势；显存占用是 `nvmlDeviceGetMemoryInfo` 已用/总容量，区分于 `nvmlUtilization_t.memory` 的读写活跃时间比例。[NVIDIA 指标说明](https://nvidia.custhelp.com/app/answers/detail/a_id/3751/kw/command)。概率图叠加 S1 / 联合 / 条件概率，统一明暗主题、网格、实际横坐标、坐标单位、淡色面积和悬停采样读数，图例可隐藏曲线。因子横轴直接使用快照的 bit / 十进制位数，不重复换算。GPU 曲线使用实际采样时间，支持 15/30/60/120 秒窗口；利用率/显存占用与功耗分图，缺失值断线。GPU时间轴固定对应所选时间窗并使用整数刻度，悬停统一显示一个实际采样时间（一位小数）及各指标，不重复x值。worker 检查区提供每曲线耗时图；横轴为采样序号，不假定为时间。概率图的图例开关和GPU时间窗为会话状态。

GPU页每设备提供可折叠卡片，数值通常以两行显示：利用率/功耗/温度，以及核心/显存频率和显存已用/总量（百分比）。窄空间允许自然换行。GPU折线固定显示对应曲线，不提供利用率/显存等图例勾选框；图内右上角显示当前读数，百分比上限为100%，功耗上限来自NVML，未知时显示`--`。常驻折线图基础高度为96逻辑单位，窄区域的标题可换行；隐藏Y轴刻度文字与重复轴标题，保留网格、整数时间刻度和完整单位悬停读数，频率趋势按需展开。概率图的Y轴及尺寸不受GPU精简格式影响。

Ely 宠物兼容固定 MIT 上游角色、七状态、边缘定位、拖动/抚摸、最小化和退出联动；使用原生透明非激活 owned 窗口及离线 atlas，无 GPUI/Web runtime。关闭释放位图，最小化暂停动画。位置跟随主窗口客户区边缘，不使用含不可见边框的外框作为落脚点。每帧先隔离再缩放，防止双三次插值采到图集中相邻帧的颜色。`pet_ely.png` 为本项目离线生成物：从固定上游 `src/pet/rig.rs` 提取矢量层，经 `tools/gen/generate_gui_v2_pet.py` 输出SVG，再由 `render_gui_v2_pet.cjs` 生成1792×1736的56帧透明图集；上游睡眠标记为两个Z。原仓库不需要包含此PNG。来源/许可及哈希见 `third_party/gui_v2_pet/` 和 `assets/gui_v2/pet_ely.json`。

“设置 → ELY皮肤”提供Classic ELY和三套装甲造型：Miss Pink Elf♪、Herrscher of Human: Ego、Hi♪ Love Elf♥。英文名及符号按装甲Wiki核对，名称来源与造型依据见 [资产说明](../../assets/gui_v2/skins/README.md)，动画可在 [离线皮肤预览](../web/ely-skins-20261022.html)比较。新皮肤沿用窗口边缘Q版比例，服饰、发型和头饰依据用户例图重绘，每套七状态×八帧；原版图集继续保留。点击立即更换，保持非激活宠物窗口及位置，清空旧帧缓存；正常退出或保存界面偏好持久化`pet.skin`。只加载当前图集，不预载全部皮肤。缺少选择的图集时提示文件名并关闭宠物，GUI继续运行。完整名称中的♪/♥使用系统Segoe UI Symbol补充字形，字体不随包分发。

## 安装与替换皮肤

皮肤PNG是外部资源，不嵌入exe，也不要求加入Git。程序固定从 **`ecm_gui_v2.exe` 同目录的 `assets` 文件夹**读取，与启动时的工作目录无关。三套新增皮肤的安装文件名为：

- `assets/pet_ely_miss_pink_elf.png`
- `assets/pet_ely_herrscher_of_human_ego.png`
- `assets/pet_ely_hi_love_elf.png`

将需要的PNG复制到该位置，启动GUI v2，在“设置”中启用ELY宠物，再点击“ELY皮肤”中的对应名称。也可运行 `ecm_gui_v2.exe --pet --pet-skin hi_love_elf`，其余两套使用对应ID。开发构建的目标目录为 `build_gui_v2_local/assets/`；本仓库资源源目录为 `assets/gui_v2/`，构建步骤仅将PNG复制到程序旁，不把它们链接进exe。

替换已登记皮肤的图案无需编译：退出程序，保留文件名并替换PNG，再启动。图片必须是1792×1736的透明RGBA动画图集，单帧224×248，8列×7行；各行依次是待机、工作、等待、异常、完成、睡觉、眨眼。文件不得超过8MiB。普通立绘或单帧PNG不能直接使用。当前运行时不读取同名JSON、SVG或`skins/manifest.json`，这些文件用于制作、来源记录与构建校验。缺少选中的PNG时仅关闭宠物并提示路径，主界面继续工作。

目前只有Classic ELY与上述三个ID，尚无文件选择式导入或自动扫描。添加一个全新的皮肤名称/ID仍须更新注册表、配置允许值及相应生成物并重新编译；仅把额外PNG放进`assets`不会增加列表项。同名PNG替换也不会实时监测文件变化，重启后加载新图。

新增PNG、SVG和素材清单仅保存在本机，按用户要求不提交Git。Git忽略规则精确放行原版`pet_ely.png`、`pet_ely.json`、[来源与生成说明](../../assets/gui_v2/CLASSIC-ELY-NOTICE.md)、[上游完整MIT许可证](../../assets/gui_v2/ELYTerminal-LICENSE.txt)及`third_party/gui_v2_pet/`中的固定源码、许可和说明；其他新增皮肤继续忽略。原版说明与许可随构建资源和候选包一同复制。运行时可按需单独安装皮肤PNG；当前开发构建及完整候选包仍校验全部本地图集/配方，新克隆工作区须先恢复这些本地资源才能通过构建。图片可通过本地备份或独立资源包保存，避免增加Git历史体积。

[网页画廊](../web/ely-skins-20261022.html)另提供三套中空浅色菱形瞳孔变体，以及现有版本切换和静态双眼放大。菱形仅绘制轮廓，中心保留虹膜底色，不使用实心填充。变体位于被忽略的`assets/web/ely_variants/`，只用于Web演示，不加入程序皮肤列表、原生资源目录、配置或程序分发包；程序仍使用现有三套图集。

## 验证边界

已有同为144 DPI的两块物理显示器、窗口几何及合成输入记录；DX11本轮有用户观察确认，Vulkan多屏拖动仍未通过。不同物理DPI、真实IME、总GPU驻留、受控功耗/计算并行、长期运行与独立干净机器仍需专项资格。系统Segoe UI / 微软雅黑 / Consolas不随包分发，缺中文字体退回英文。可选Vulkan路径遇HDR/显示格式改变导致render pass不兼容时要求重启。

`--validation`、`--no-loader`、`--inject-failure`和`--trace-render`仅适用于显式Vulkan模式；DX11拒绝这些组合，不伪造Vulkan验证通过。`--frames`、`--audit-ui`、`--audit-app`、`--simulate-missing-cjk`是公共测试入口。显式Vulkan分配只计VkDeviceMemory，DX11日志明确标注该统计不提供D3D显存数据；两者均不是进程总显存，不能据API名称声明更低占用。验证脚本位于 `tools/test/gui_v2/`，证据存忽略目录 `data/experiments/gui_v2/`。

## 独立候选包

先用独立构建入口生成程序，再运行 `tools/build/package_gui_v2.ps1 -BuildDir build_gui_v2_local -Output <新的目录>`；可用 `-Python` 指定解释器。包包含 GUI、宠物资产、使用/侧车说明、许可、逐文件 SHA256、构建源目录快照及 ZIP 校验，不覆盖旧版。不包含计算 worker、系统字体、Vulkan loader、开发层或 Microsoft runtime；更新 worker 另行安装，1024-bit 专用验收 worker 不能作为完整发布替代。

v2 自带 UTF-8 进程 manifest，使复用的窄字符文件接口在支持的 Windows 版本上处理中文路径；不改变系统代码页或旧 GUI。依据：[Microsoft 进程 UTF-8 文档](https://learn.microsoft.com/en-us/windows/apps/design/globalizing/use-utf8-code-page)。计算 worker 的非 ASCII 路径兼容性须按其自身构建单独确认。

P5未完成默认DX11后端的完整性能矩阵；历史Vulkan矩阵的最小化CPU中位数1.031% > 1%失败及桌面冻结结论保留，不转记为DX11测量。P6是独立分发准备，不表示已获得全部生产资格；未放宽门限。具体输入、设备、二进制、样本及时间边界见实施草稿，原始失败证据保留。可显式使用`--no-nvml`关闭监控，但不据此改判默认监控条件下的门禁。
