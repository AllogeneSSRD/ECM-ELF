素数、标量乘法与搜索种子

筛法给出素数 p。 例如 B₁=10 时，素数是 2, 3, 5, 7。LCM 模式的标量是 S=2³·3²·5·7=2520。连续执行 [2]、[2]、[2]、[3]、[3]、[5]、[7]，得到 P → [2]P → [4]P → [8]P → [24]P → [72]P → [360]P → [2520]P。对应关系是 [a]([b]P)=[ab]P。每个 p 重复到其最高幂 pᵏ ≤ B₁，同一条链可以重复用。choose12 模式还乘 12=2²·3。

PRAC 搜索的是种子 r。 它满足 p/2 < r < p，可以是合数。比如乘数 p=5、种子 r=3，先倍点得 2P，再用输入 P、2P 和已知差点 P 得到 3P，最后用 2P、3P 和差点 P 得到 5P。差分加法要求已知差点的横坐标。若目标是求两个点的差，可以把第二个点取负，使用已知和点的横坐标作为差分输入。合法奇素数种子的 gcd(2r−p,p−r)=1，所以系数归约到 (1,1)。p=2 只倍点一次。本页和 ECM-ELF 的这个计划器使用逐素数规则，合数乘数需要额外处理。

提高 B₁ 与加宽搜索是两个变量。 提高 B₁ 会纳入新的素数及更高素数幂。如果曲线点在未知因子 q 上的阶整除 S，该点乘到无穷远，才有机会从投影分母的 GCD 提取 q。比如点阶是 25，B₁=10 时仅含一次 5，到 B₁=25 才覆盖 5²。只增加素数个数未必补足所缺的幂，还会增加运行工作。固定 B₁ 加宽搜索只增加候选种子，目标乘数和覆盖范围照旧，收益来自选中的点运算链成本下降。
