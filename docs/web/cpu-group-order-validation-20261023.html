已实现范围

试除、完全幂、Pollard–Brent rho；保留余因子的部分结果；正确模型映射；Jacobian 标量乘；枚举及 BSGS/Mestre 配合二次扭曲 CRT 的群阶计数；从已知群阶或其他消去倍数恢复原始点阶。输入倍数不会被标为已计算群阶。

完整计数受 baby 表预算限制，38～49 位十进制 Edwards 参考全部明确停止。主程序已接入有预算的 GP 回退；SEA、补充分解后端与大整数素性证明尚未实现。计数性能优化可研究批量归一化和表结构。
