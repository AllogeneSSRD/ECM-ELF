# Stage2 性能与规模关系

## 计时与实验条件

主指标为 `stage2_full_wall.total=init+main`：包括 baby/F 树、必需自检、inverse、giant/G/fold、下降、GCD 与算术检查收尾；排除 Stage1、进程启动及独立自动 D 扫描。外层 result/curve_done 的时间另计。

`t_reduce` 和 NTT 秒数嵌套在树/fold/下降中，不再次加入总时间或100%图。各模块容量/峰不直接相加为进程峰。GPU 利用率采样不是 SM occupancy，自身事件间隙不证明整张卡空闲。

位宽扫描和三项固定输入 A/B 使用 GPU1 RTX4060 Laptop、默认1800MHz/55W；GPU0 既有任务未隔离。它们绑定不同冻结二进制，不能把差额解释为单项优化效果。临时高功率数据不加入主表。另列的 B2 预算扫描保留其自身实验条件，只用于规模关系，不合并绝对秒数。

## B2 和位宽关系

固定 D/P 时 I≈B2/D，G≈B2/(DP)，主重复成本近似 Tfixed+G·Tbatch，所以大 B2 可近线性。允许 P/D 随预算增长时可呈约平方根；驻留不是平方根的充分条件，owner 回退也不是线性的充分条件。

预算扫描的独立反例：4423-bit 非驻留但 D/P 增长时相邻幂指数约0.54…0.55；驻留但 D/P 固定时约0.93…0.98。固定 D1021020/P92160 的三点拟合为驻留 T≈9.9112+1.7507G、回退 T≈9.5072+1.9377G 秒，仅说明固定项+批成本，不能发布为通用模型。

该批冻结 exe SHA=`893f6e907c17803ed90b09b98ffbf6b85e08b7deb1335a9d6c6efd1f8a01f69d`；策略网格每格单次、固定 D 每模式每 B2 两次，无置信区间。功耗条件未与55W主表闭合，不用于绝对性能横比。原始结果及测量身份见 `data/experiments/stage2_budget_scaling_20261005_summary.json`、同名 audit/CSV 与实验记录。

位宽成本同时含 NTT 的 Σbatch·L·log₂L、系数通用归约约 Ccoeff·W²、点乘 O(IW²)，以及准备/传输/GCD。L 取2的幂，预算还会迫使 P 下降和 G 增加，单一 S/B2 幂函数只能估量级。

完整梅森/承载 S4 折叠主体近 O(W)，但点乘积仍有 W²，NTT仍需宽系数 packing。完整梅森含小因子的非单位回退可能主导时间，不能把其单次对照比值全归因于归约。
