# GUI 概率面板草稿

## 需求与实现范围

用户要求增加类似 tools/ecm_prob 的概率输入、反算和 GUI 曲线图。复用 src/core/ecm_stage2_probability.h 的原生 local Dickman／半光滑数值核心，不调用 Python、不链接 GMP/CUDA，不启动 ECM 曲线。

面板使用同一概率核心计算 Stage1、完整流程及 Stage1 失败后 Stage2 的条件概率。因子大小可使用二进制位数或十进制位数；代表值分别为 2^(b−0.5)、10^(d−0.5)。输入 B1、固定 B2 或 B2/B1、曲线数及 D_eff；预设采用 tools/ecm_prob/model.py 的 GMP 理论常数。自定义 D_eff 接受外部拟合值，但不自动导入未追踪的经验 JSON。T=4/8/12/16 明确标记为仅扭转基线，不作为曲线实测数据。

反算目标可选单曲线概率或累计成功率；支持曲线数、因子大小、B1、B2 和 D_eff。未知输入字段禁用。曲线数只能按累计概率反算，B2 要求启用 Stage2。条件 Stage2 概率对 B1 不单调，因此该组合拒绝二分反算并说明原因。B1/B2 输出取整，边界已满足目标时直接返回最小允许界限；否则在有限范围内做80次括区间搜索，报告采用参数下的概率及目标残差。

图表分别展示因子大小与单曲线概率、曲线数与累计概率，使用129个点；包含 Stage1/完整流程及可选条件概率。支持悬停、当前参数标记、对数概率轴、范围输入和复制曲线 CSV。对数轴跳过零值，无定义的条件概率不补零。界面输入改变后标记待计算，后台任务使用快照，图表明确显示结果所用参数；不会把未计算的新输入当成已完成结果。

新窗口使用稳定标识 ###prob，加入默认 worker 节点；已保存布局通过首次使用的停靠提示加入，不重置布局版本。查看菜单可打开或聚焦，关闭后可以重新打开；start_tab=prob 可直接进入。计算字段为本次 GUI 会话状态，不新增 INI 参数副本。

## 工程依据与验证边界

- probability_model.h/.cpp：输入范围、概率组合、稳定累计/未命中计算、反算及 CSV。
- probability_panel.h/.cpp：CPU后台任务、输入、数值结果与图表。
- app.cpp、src/gui/CMakeLists.txt：窗口、菜单、停靠及构建集成。
- config/ecm_options.json：start_tab 扩展；经生成器同步模板、绑定和配置说明。
- 中英 XML：全部新增按钮、参数、错误及模型条件说明。

现有核心的对拍证据只用于说明复用组件，不构成本轮面板或反算验证。本轮依照开发约束只构建，不添加或运行测试；待验证理论预设与 Python 工具的概率对拍、各反算残差、条件概率边界、极小概率、大字体和窄窗口、后台计算期间修改输入、菜单重开及已保存布局。

模型的默认数值截断可能给出零，不表示严格不可能命中。独立等效曲线假设不保证给定有限 sigma 组的真实命中率。不计入 Brent–Suyama 或额外 Stage1×12 的收益；D_eff 与 Stage2 选型 D 无关。草稿保留，完成后由用户决定整理。
