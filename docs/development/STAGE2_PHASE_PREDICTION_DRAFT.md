# Stage2 同位宽分阶段预测实验

目标：改进运行时有限 D 搜索的候选排序，使同一 NTT 区间内的新 D 能利用当前算术后端的实际阶段占比。冷启动默认 D、搜索预算、内存准入和稳定参数的实测替换规则保持不变。

实验限定：候选与观测具有相同的实际位宽、点算术和 S4 后端、链长、尾部策略、布局、驻留状态及 NTT 区间；设备、驱动、CUDA、环境和预算条件全部匹配。P 与巨步点数分别限定在观测值的一半至两倍。跨位宽、跨 NTT 或调度边界仍使用现有区间模型。

完整的十项互斥阶段均值必须守恒到引擎总时间。符合条件时，使用已有的分阶段工作量缩放模型生成候选预测，保留至少 15% 的模型误差余量；预测不标记为独立验证，不增加测量次数。确切运行时测量和正式测量优先于预测。

待验证：

- CPU：守恒、缺失阶段、环境隔离、区域边界、缓存一致性，以及测量优先级。
- 生产路径：冻结 Stage1 输入，使用旧二进制获取单个默认 D 的观测；新候选的已知耗时不参与训练。
- GPU1：4060 Laptop，保持已有硬件设置；以固定 D 独立复测检验有限搜索结果。
- 不更改无 tune 默认参数；不将本轮两格局部结果推广为全位宽保证。

该文件是开发临时草稿，实验完成后由用户决定如何处理。

## 验证记录

实现限制为运行时试跑的预测器，默认构造的位宽预测器保持原行为。生产代码在`planning/width_prediction.h`，两个运行时入口在`planning/planning.cpp`。没有修改配置键、tune格式、D表或CUDA算术。

完成两格真实队列学习、各侧一次独立固定D复测和52格无tune原生规划比较。12285-bit的独立默认/优选时间为60.573/50.171s；16272-bit为72.386/69.921s。GPU忙碌窗口均1500MHz；全部自检和抽查通过。

已否定“旧模型有相同观测仍会漏掉这两个首选D”的初始假设：原整曲线修正也会提议510510和395010。本实现的直接验证是两格预测误差缩小，不能将完整参数收益全部归因于新模型，也没有新旧运行时学习矩阵的整体加速结论。

测试初版的合成条件缺少驱动/CUDA/后端字段，导致严格匹配失败；补齐正确测试条件后通过，未放宽生产匹配条件。沙盒内NVML报告白名单进程路径不可读，门禁拒绝启动；沙盒外读取到真实路径后沿用相同白名单。首轮失败证据保留。
