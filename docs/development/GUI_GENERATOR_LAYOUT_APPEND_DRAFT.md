# GUI 生成器布局与分段追加开发草稿

## 需求

- 曲线选项改为两列：第一行是推荐曲线数和去重勾选框，第二行是块/SM 和目标显卡。
- 输出选项改为两列：第一行是覆盖 B1 和存档名，第二行是排序下拉框。
- 目标 worktodo 已有 `[Worker #N]` 标签时，新任务加入对应 worker 最后一个分段的末尾。本轮修改暂不提交。

## 实现与依据

- `src/gui/app.cpp` 使用两列选项表。每个输入框占满所在单元格宽度；排序选项来自 `src/gui/worktodo_gen.cpp` 支持的字段，另保留 `n,k,b,c` 组合。
- `src/gui/worktodo_gen.cpp` 用 `src/core/ecm_ini.h` 的 worker 标签规则定位分段。已有标签下只插入新任务，不重复标签；缺失标签在文件末尾补建。
- 目标原内容按字节保留。目标存在分段时先写临时文件、再次核对目标内容，再替换目标文件；无分段时沿用末尾追加。预览与写入之间用大小、修改时间和内容摘要检测变化。

## 验证

- 2026-10-11：先用已有 worker 标签的目标文件复现：旧版在文件末尾重复标签，导致 worker 1 的新任务出现在 worker 2 标签后；两项位置检查失败。
- `ecm_gui` 与 `ecm_gui_gen_test` 构建通过；生成器测试 98/98 通过，涵盖已有标签、重复标签、缺失标签、无标签预览拒绝写入、等长外部改写；GUI 自检 36/36 通过。
