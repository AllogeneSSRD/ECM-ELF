# Stage2 outer 计划优化草稿

状态：本轮实现、固定D验证和剖析完成；生产默认策略未修改。

## 目标与实验约束

比较 k21–23 的现有 M4 与协作 M5–M8，验证减少 outer 遍历能否降低完整卷积成本。使用生产运行时、固定 Goldilocks PTX3 算术；不由遍历数或算子结果直接推断整条曲线收益。

设备为 GPU1 RTX 4060 Laptop，保持默认 55 W、1800 MHz 上限，不调整功率或频率；GPU0 的外部任务保持运行。实测频率及传感器异常另行记录。

## 验证与证据

- 独立 GMP 正向、逆向及缓存生命周期门禁；故障注入必须被检出。
- 同二进制、相同输入、交错顺序比较；每个正式样本核对完整 A/B 输出。
- 先比较算子；候选有稳定收益后再做固定 D 完整 Stage2 A/B，保留原默认路径。
- 原始记录置于 `data/experiments/stage2_outer_plan_20261015/`，汇总置于 `data/benchmarks/stage2_outer_plan_20261015/`。
