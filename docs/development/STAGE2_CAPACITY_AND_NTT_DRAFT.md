# Stage2 容量与物理 NTT 形状实验草稿

本实验分别验证普通除数缓存、承载多项式路径、有限队列预算和大 B2 驻留边界。证据目录为 `data/experiments/stage2_s4_capacity_20261103/`。设备为 GPU1 RTX 4060 Laptop，性能调用串行执行。所有首轮、反序和慢样本均保留。

- 普通路径先在同一原语探针中比较固定九组与有限容量，再通过最终生产分派核对 GMP、故障和完整叶摘要。10232、12285 bits 各冻结 D570570，分别以 3/4/4/3 和 4/3/3/4 顺序运行。首轮两侧均值回退超过 3% 的格追加一对独立样本。注册数、S4 事件和曲线墙钟分别判断。当前实现依据见[归约报告](../performance/STAGE2_S4_REDUCTION.md#按实际除数位宽选择缓存容量)。
- 承载路径在 D510510 和 D395010 的完整已核对保存点上执行 Nsight Systems 诊断。按提交线程、相关 ID 及真实物理 batch 确认 GPU kernel 所属的 G 树或驻留 fold。算子扫描比较生产 tile 与 outer 参数，单独保留复测。
- 队列策略离线回放。首先保留一个新 D 试跑机会，然后比较预计的额外试跑代价与剩余曲线的可能节省。提前停止时同时记录错过的实际胜者。
- 边界实验固定 10267-bit 承载、B2=2600000000000，先原生规划共享表中相邻的 D510510、513240，再按 owner 字节数向下取预算。生产入口要求开启设备 frontier，实验用其独立 1 MiB 容量预算使三组均走 host frontier，并记录实际 fold 启用状态。原生规划在 arena=6300 和1536 MiB 时拒绝这些几何，768 MiB 下三组通过。

10232-bit 反序调用出现慢样本，S4 事件仍为 11.564s，而下降达 16.06s。第三对复测用于评估整曲线离散。正式结论以性能主题中的完整样本和证据位置为准。本草稿由用户决定后续处理。

验证已完成。原语收益在W159/160最明显，两格整曲线中位数均轻微回退。长度2²⁷的默认计划在独立复测中与最优请求持平，长度2¹³、物理batch 1215 的tile10在独立算子对照中节省3.18%。B2边界三条完整曲线与回放的反例均保留，见[大B2性能](../performance/STAGE2_LARGE_B2.md#固定d的承载追踪与大b2准入)和[队列预算](../architecture/AUTO_B2.md#实测统计与路径保留)。
