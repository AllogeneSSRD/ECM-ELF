## 输入核对与转换

源文件 1056 条均为 PARAM0、完整无因子回执。先冻结原文，按实际 N/sigma/B1/参数化去重，每条曲线只保留最大完成 B2，得到 1026 条：17 条完全重复、13 条较小 B2 被覆盖。M3877、M12011、M12037 分别 66、480、480 条。

三份余因子为 3275/11694/11616 位，用本地因子目录中的已知因子精确重建；三个实际 N 的 Miller–Rabin 基数 3 均给出合数见证。转换器不接纳没有合数见证的目标，避免把素数测试输入当作有用 ECM 提交。

剩余行只按相邻源行、递增 save 记录和相同工作合并，得到 7 个批次，时间采用末条真实 UTC 完成时间。四批的实际 D/poly-size 可从原始日志完整关联且整批一致，其余批次省略；GPU 多层 NTT 不虚构单一 Stage2 FFT。FFT 报告参考值为正，CRC 按最终输出字段重算。同目录 INI 没有身份值，输出省略 user/computer/AID。

最终源证据与转换结果在 `final/`；原目录中的副本为 `submission_20261017/results.json.txt`，审计文件并列保存。输入 JSONL 未更改，没有网络提交。
