# Stage2 tune 与选型修正草稿

本文是开发草稿。完成验证后，将有效结论写入正式说明，并提示维护者处理本文；原始证据不删除。

## 验收目标

- TOML 使用 `matrix`，第一行是列名，后续行为最终摘要，列位置对齐。
- tune 控制台保留窗口、重复进度、结束与失败原因；内部曲线诊断保存在证据日志。
- D 从模型起点出发，对邻项作完整曲线比较；有显著收益才移动，不展开笛卡尔积。
- 默认结果与上一轮生产扫描至少持平；tune 不以未经实测的预测覆盖默认结果。
- 用户确认验收按完整余因子矩阵总耗时不增加；明显单项回退另外复测，单次测量的几％波动不直接判为回退。
- B1 不作为 tune 匹配条件；显存准入与算术检查保持有效。

## 当前实现及待验证内容

格式版本为 7。读取器将第一行映射到字段名，拒绝重复列、错误列数、嵌套单元格、重复候选及失败的算术证据。旧格式不自动作为生产性能数据读取。用于本次实验的旧表在忽略目录中另存原件，转换副本经标量一致性比较和原生读回验证。

离散搜索从默认模型的 D 开始，比较邻档；只有中位数降低超过 2%，并超过双方 2×MAD 噪声界限时移动。端点、显存拒绝或预算终止会收缩可继续搜索的范围。再次 tune 复用达到重复要求的已测项，不重新展开全表。默认网格额外加入真实默认 D；显式 D 表保持用户给出的范围。

默认模型在低于后端最大 NTT 长度时保留原生模型；达到 2²⁷ 后，仅比较不改变最大 NTT 长度且仍驻留的更大 D。归一化阶段权重来源于先前生产曲线的阶段占比，仍须通过新运行验证，不能作为已证实的普遍收益。

正式固定 B2 选型要求默认 D 和替代 D 有同位宽、同 B2、同算术及执行路径的实测。B1 不参与匹配。替代项需跨过相同的中位数/MAD 改善界限。没有成对证据时保留默认 D；启动短探测不能据此宣称高 B2 选型更快。

跨 D 预测新增非负拟合：固定项、NTT 工作量、归约工作量、点运算工作量。至少六个完整曲线摘要、三个 D、两个 B2，留一误差须不超过门限；P=24 探测不进入该拟合。稀疏模型仍显式标为估算，不用于覆盖默认 D。此拟合没有取消 Auto B2 的 Stage1 成本、概率、内存及误差余量要求。

## 中间反馈

原型默认扫描中，6797-bit/B2=2.6e11选择更大的D=1021020，30.589秒，优于上一轮46.850秒但慢于更早基准约7%。最终模型针对通用归约增加默认巨步数≥16P的摊销门槛；该门槛不套到快速梅森归约。原型证据完整保留，最终构建须独立复测余因子矩阵。

第一轮tune正式矩阵已完成的23格中，引擎时间减少约7秒，进程时间增加约46.5秒。固定B2仍对大量无胜出实测的D进行预测及原生规划，增加主机成本。新增实测摘要预筛：只有可能跨过成对改善界限的候选进入完整规划；后续严格路线匹配、显存准入和最终free检查保留。选型身份及完整矩阵需要独立验证。

实测预筛及同次默认D复用后，27格仅规划查询111.093→27.424秒，D/P/排名、原生请求程序及giant路径一致。最终矩阵的引擎与进程合计均优于默认；中间全矩阵与冻结身份分别保留，不混合统计。

最后的无文件/关闭短校准/未锁D检查在`default_plans_final/`复现缓存字段缺失异常。修正为仅在返回记录含`default_D`时读取缓存，否则计算默认D；补充GPU专门门禁。当前本机构建SHA256=`50171511de1dbc9b998e7a352173edbac4bc70cb181bb6c81da442e542d4e659`，22项GPU检查及27格默认选型核对通过，同一CUDA对象不变。该guard修改不冒充已测矩阵二进制；最终完整计时仍引用4625构建。

生产参数文件已发布为格式7：`stage2_tune.toml`保留48条NTT摘要，`stage2_ecm_tune.toml`保留79条ECM与52条NTT最终摘要。验证完成后才合入本次正式结果；旧文件、转换副本及导入来源证据留在忽略目录。

当前exe与更新后生产profile复现27格D/P/I，见`production_profile_plans/report.json`；NTT原测量保持不变、全部ECM候选只保留相同或更快中位数，见`production_profiles_receipt.json`。该查询检查不作为额外计时样本。
