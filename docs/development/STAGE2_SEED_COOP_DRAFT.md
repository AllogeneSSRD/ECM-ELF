# Stage2 seed协作优化草稿

目标：复用已验证的TPI32点域与binary ladder，优化paired seed及GPU构建[D]Q；保持标量、相同点数／NTT工作量、坐标布局和非单位回退。

现有0.57.9小B2矩阵的最高位：普通49.164s、承载25.779s。承载giant及叶准备6.576s；相同几何的已有管理员轨迹中paired seed约3.667s、[D]Q约1.039s。轨迹为剖析参考，不直接作为本轮性能成绩；G树／fold／下降另占承载44.38%，不得称为纯NTT时间。

先做生产算术头的独立GMP／跨后端坐标核对及事件测试，再做固定D、布局、链长、baby／giant后端的完整曲线A/B。保留所有首轮、失败和原始结果。运行GPU1，记录实际频率及进程门禁，不修改设备设置，不在计时期间编译。

策略须单独标识，旧标量seed成本不能与新策略混合；NTT表不受seed策略影响。先保留默认标量及旧性能保护，再依据覆盖情况决定配置默认与运行时学习的接入。不可仅凭kernel倍率启用全局默认。

证据计划放在`data/experiments/stage2_seed_coop_20261102/`，汇总与图放在相应benchmarks／figures目录。此草稿保留，完成后提示用户处理。

## 实施与资格结果

0.57.11实现独立seed策略，默认scalar；相邻点复用既有协作ladder，不改数学工作量和缓冲布局。配置优先级、子进程继承、ECM强成本身份和NTT复用已接入。

四容量166次边界资格通过（含4次预期拒绝故障）；四档96个事件样本保留。8条原生叶／seed诊断、真实worker配置与性能文件增量、8207-bit非单位回退通过。八格16次正常曲线全部NF，合计引擎减少14.02%，完整curve wall减少13.56%。7995-bit的初次承载波动另补至每组3次；同一标量kernel的外层波动不能归因于协作收益。默认旧版对照保持同工作量／根摘要，单次约+0.20%。

失败证据均保留：correct_w160无法在受限查询中绑定白名单；correct02_w160缺少输出，后续单独诊断同命令通过，不推定原因；native_checks01采集器漏开target leaf hash，补开后重新完整执行；nonunit01的缩短chain阈值被生产guard正确拒绝，改用生产允许的10017点后验证通过。没有放宽门禁或删除首轮。

最高位普通S4仍约15.67s，占优化后引擎38.27%；承载仅0.907s，树／fold／下降仍54.43%。下一步按两条算术路线分别定位归约与NTT／提交成本；不将阶段范围相加或当作纯NTT。
