# CUDA 可视化网页交付草稿

本轮在 `web/` 增加架构讲解页面，不修改 CUDA/核心算法、配置、存档、输出或版本号。当前架构依据为0.44.5，主要源码修订为 `5d15a93`。

页面覆盖程序/文件交接边界、主机与设备目录职责、Stage2的15个主机模块、编译过程与缓存失效、五条运行路径、位宽/容量示例及源码索引。运行图表示职责与主要数据顺序，明确区分正常曲线、plan和纯NTT tune，不执行GPU任务。

人工讲解在 `web/architecture.content.json`；生成器 `tools/gen/generate_cuda_architecture_web.py` 直接调用权威CMake清单并读取实际源码，生成离线JS快照。维护和打开方式以 `web/README.md` 为准。检查时发现Stage1说明中的旧核目录和P2拆分TODO已失效，已按当前源码修正文档。

浏览器检查记录保存在忽略目录 `data/experiments/cuda_architecture_web/`。已核对Stage1默认57单元（31CU/26CPP）、显式PRAC的69单元（42CU/27CPP）、Stage2生产25单元、实验5单元；五条流程的首末步/边界、源码搜索及弹窗/键盘关闭、位数边界、桌面与390px移动布局。检查不运行CUDA，不构成算法或性能验收。

静态检查包括JS语法、生成快照与源清单/路径/符号的一致性、页面本地资产和引用完整性。原生预览服务器通过localhost提供页面；沙箱内服务首次无法被浏览器连接，改用本机服务后HTTP200及浏览器检查通过，未更改防火墙或安全设置。

正式使用入口已加入 `docs/README.md`。本草稿保留，交付后提示用户处理，不自动删除。
