# Stage2 点专用平方验证草稿

分析基线为0.57.0；正式位宽模型见[位宽报告](../performance/STAGE2_BIT_SCALING.md)。本草稿记录实验与验收，完成后由用户决定是否清理。

## 实现与边界

生产原语中分离公共Montgomery／梅森归约；专用平方只替换完整乘积，使用严格上三角、整段左移和对角线加法，将部分积从W²降到W(W+1)/2，输入／输出尺度和原地覆盖合同保持。普通REDC仍为平方工作量。

首轮独立探针直接包含生产头，不使用旧实验副本。GMP检查全部输出，覆盖边界值、随机奇数、接近radix的模数、精确梅森及非64-bit对齐位宽；独立故障注入检查验证器能拒绝错误。

只有独立正确性、并发／依赖测量及固定D完整Stage2通过后才决定生产启用范围和默认值；当前未验证候选不写成生产性能收益。原始日志和失败样本保留在`data/experiments/stage2_point_square_20261101/`。

## 已完成验证

- `correctness_full/`：32个位宽、三类模数、两种输出别名、专用函数／生产包装，共384条合法调用；每条64个输入、3次依赖平方。全部输出与GMP一致。第385条故障注入被拒绝，原日志保留。
- `curve_diagnostics/`：目标7995／16272 bits，普通／承载，旧版、同二进制off／on共12条。B1=50000、B2=2600000、D2310／P240，完整leaf检查及目标叶指纹均一致，mandatory／GMP／xADD检查通过。这些诊断时间不充当生产性能样本。
- `initial_memory_fixed/`：50组原生分配与模型核对，4556项检查／1500项事件核对通过；扩大baby树容量的变异被拒绝。修正了测试中失效的copy／旧include路径锚点，保留原强度，并断言额外平方检查没有增加设备分配。
- `micro_first/`保留首轮性能探索：已冻结探针包含生产原语；每个调用保留全部5次事件，GPU1繁忙样本SM1500MHz。元数据查询边界随最终探针明确，首轮不与后续样本混合。

## 构建环境

受限编译与单独重编均在ptxas报INVALID_HANDLE，日志保留`compiler_first/`。取消强制内联的单变量探针同样失败，保留`compiler_noinline/`。用户指出既有[句柄诊断](PTXAS_SANDBOX_DIAGNOSIS_DRAFT.md)后，恢复原内联、保持split=8，在沙盒外按正式脚本编译成功，135.4秒，44单元前／后检查通过。此结果不把编译环境错误归因于平方算法。

## 正常性能资格

`curves_low_full/`已完成13位宽×普通／承载×旧版／off／on各n=1，共78次；固定D／布局／链长和Stage1点。旧版／off／on合计375.369331／375.556822／358.873123秒，on比旧版减少4.39466%，无同时超过5%与20ms的回退格。普通合计减少3.26193%、承载减少6.21371%。NTT长度／归约系数数／G根摘要逐格一致。汇总及图保留于`data/benchmarks/stage2_point_square_20261101/screening/`及对应figures目录。

0.57.1提交可选实现，保持默认关闭；下一步单独验证默认启用与显式关闭／子进程继承，按用户要求递增版本提交。正式当前状态只在位宽报告维护。
