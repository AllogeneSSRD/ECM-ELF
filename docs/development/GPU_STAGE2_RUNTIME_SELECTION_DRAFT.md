# Stage2 正常运行样本累计与自动承载选型草稿

本草稿记录本轮开发与验证，完成后保留，由用户决定后续处理。当前正式规则另同步到 Auto B2/tune 说明。

## 问题与目标

4916-bit、B2=1.3×10¹² 的两条正常运行摘要分别为 D690690 的52.873秒和 D1381380 的45.183秒。原实现只保留最快单次结果，区间已有样本就停止采集；这些记录不能建立精确比较，双侧至少15%的模型余量导致选型退回默认。

本轮按同设备、环境、算术和执行形状累计独立NF样本，默认每组最多10次；中位数和MAD来自实际样本。合法梅森承载作为正常运行的首个试跑候选，随后建立普通基线及有希望的D比较。预计30%的优势只用于候选优先级，不作为收益证明。显式D/承载锁、关闭采集、算术验证及实时显存准入仍有效。

## 设计与待验证条件

- 保留有限个独立标量样本及去重身份，不把较慢样本丢掉，不改写忽略目录内的原始证据。正式重复调优摘要继续独立维护。
- 同条件比较至少需要两次成功NF；单次样本继续作为模型校准和后续试跑依据。
- 比较使用中位数、实际MAD和2%的切换余量；已完成生产路径作为优先保留对象，只有另一条路径显示优势才切换，避免误差区间重叠时退回默认。
- 试跑使用待处理曲线，完整执行并正常保存结果；命中、回退、失败或中断不能计为NF样本。承载必须先核对目标N整除2^p−1。
- 待验证：旧摘要延续、重复导入去重、上限与并发发布、不同构建/环境隔离、承载优先与显式锁、因子一致、关闭功能和真实GPU全流程。
