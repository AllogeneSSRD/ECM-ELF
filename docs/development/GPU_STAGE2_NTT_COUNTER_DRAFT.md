# GPU Stage2 NTT 长度计数器草稿

本临时草稿记录通用 CUDA Stage2 计数器开发，完成后保留，待用户处理。正式说明维护在 `docs/architecture/NTT.md`，真实运行日志与性能证据保存在忽略的 `data/experiments/stage2_ntt_counts_20261017/`。

## 范围与实现

Edwards 和 Montgomery 共用生产多项式引擎。沿用已核对的数学计数口径：每次卷积的每个 batch 成员执行两个正向 NTT 和一个逆向 NTT；Graph 重放与物理分块不改变该计数。统计曲线初始化及主计算的多项式请求，不包含 Stage1 或底层独立算术自检。

新增 `stage2_ntt_counts=0|1`，默认关闭；CLI `--ntt-counts` 覆盖选定 worker 的 INI。开启后每条曲线结束输出按长度排序的表，保留已有机器可读的长度直方图与工作量行。计数在主机多项式调用完成处进行，不增加设备原子操作、显存分配、CUDA event 或同步。实验引擎不支持此选项，开启时报错。新增功能版本为 0.32.0。

## 验证计划

核对默认关闭、INI/worker/CLI 优先级、非法值拒绝；GPU1 上用 Edwards/Montgomery 输入验证计数、批量与末点因子检查。固定输入及 D 交替运行开关两种设置，保留首轮、原始引擎时间和波动，不把计数输出时间重复加到嵌套计时。既有性能矩阵继续使用冻结二进制，不混入新版本。

## 已完成验证

生产 CUDA 构建通过；配置由 schema 生成且一致性检查通过。13 项 GPU1 门禁覆盖开关默认值、worker/CLI 优先级、quiet 控制台、Edwards/Montgomery、逐曲线重置、非法值拒绝；与旧冻结程序的直方图和叶值 hash 一致。CPU 0.32.0 版本同步构建并通过 16 项结果输出门禁。

开销对照每个输入/设置 5 次，两个实际余因子为 383 和 10232 bits，均固定 D=180180、B1=50000、B2=27,015,978,990。中位变化 +1.52%/−0.17%，配对值有正有负，当前样本没有稳定损失。未控制功率/时钟，CPU 基准在后台；进程耗时同时保留，正式边界与数据见 NTT 权威说明。原始 `perf_01` 的大输入在算术通过后因通用 N 的提交行超长失败，工具补充 `--study` 读取精确目标元数据，后续 `perf_02` 完成该输入全部样本；失败回执不当作计时样本。
