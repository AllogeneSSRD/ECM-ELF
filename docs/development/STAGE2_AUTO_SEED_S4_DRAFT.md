# Stage2 auto seed与普通S4优化草稿

目标：seed支持auto，复用现有最少重复数和有界对照／默认保护；以真实执行后端记账，NTT表继续复用。先建立S4普通路线NCU基线，再按相依MAC、local访问和发射效率的证据选择实验。所有原始失败、首轮、剖析与计时分开保留，不改GPU设置。

基线：0.57.11，commit927a514a，GPU1 RTX4060 Laptop，目标1500MHz／55W，最高位普通S4设备事件约15.67s。冻结EXE和真实固定D命令于data/experiments/stage2_s4_20261102/baseline及ncu_baseline_200；管理员NCU不控制clock/cache，剖析时间不作性能成绩。

auto需要新增实际seed_coop矩阵轴；旧标量资料保留，旧非零请求不能猜成实际协作。配置默认auto先走标量，按R次重复完成同形状对照后选择最快合格项；baby、giant、seed顺次有界探索，不能让D候选与后端形成笛卡尔积。

## Auto seed实施与验证

0.57.12使用实际seed_coop矩阵轴与format11，默认auto先走标量，保持未配对／重复数／有限探索保护。旧标量资料保留，非零环境请求缺实证记为未知255；NTT表继续复用。父子进程显式转发最终后端，正式tune复用相邻D配对胜者。

最终运行28条NF通过，R2为0,0,32,32并持续复用，R1承载、三后端联合auto和有限32／64链长及关闭学习均通过。真实worker配置3条曲线和1例非法值拒绝通过。正式调优D30030只生成两条后端行，D27300只增胜者一条，再次运行不增测量。CPU资格图验证链长完整对照可保留只读胜者，避免要求全部参数笛卡尔积。

S4研究独立于auto：216次当前原语资格（9宽度、三类digit位宽、多batch、四类模数、两后端）及8次故障拒绝通过。初次探针输入超过slot_bits的padding被生产guard正确拒绝，修正生成器，不放宽检查。早期吞吐探索显示warp和缓存窗口有收益；仍需生产接入及整曲线验证，不能将原语倍率写成生产结果。
