# Stage2 auto seed与普通S4优化草稿

目标：seed支持auto，复用现有最少重复数和有界对照／默认保护；以真实执行后端记账，NTT表继续复用。先建立S4普通路线NCU基线，再按相依MAC、local访问和发射效率的证据选择实验。所有原始失败、首轮、剖析与计时分开保留，不改GPU设置。

基线：0.57.11，commit927a514a，GPU1 RTX4060 Laptop，目标1500MHz／55W，最高位普通S4设备事件约15.67s。冻结EXE和真实固定D命令于data/experiments/stage2_s4_20261102/baseline及ncu_baseline_200；管理员NCU不控制clock/cache，剖析时间不作性能成绩。

auto需要新增实际seed_coop矩阵轴；旧标量资料保留，旧非零请求不能猜成实际协作。配置默认auto先走标量，按R次重复完成同形状对照后选择最快合格项；baby、giant、seed顺次有界探索，不能让D候选与后端形成笛卡尔积。

## Auto seed实施与验证

0.57.12使用实际seed_coop矩阵轴与format11，默认auto先走标量，保持未配对／重复数／有限探索保护。旧标量资料保留，非零环境请求缺实证记为未知255；NTT表继续复用。父子进程显式转发最终后端，正式tune复用相邻D配对胜者。

最终运行28条NF通过，R2为0,0,32,32并持续复用，R1承载、三后端联合auto和有限32／64链长及关闭学习均通过。真实worker配置3条曲线和1例非法值拒绝通过。正式调优D30030只生成两条后端行，D27300只增胜者一条，再次运行不增测量。CPU资格图验证链长完整对照可保留只读胜者，避免要求全部参数笛卡尔积。

S4研究独立于auto：216次当前原语资格（9宽度、三类digit位宽、多batch、四类模数、两后端）及8次故障拒绝通过。初次探针输入超过slot_bits的padding被生产guard正确拒绝，修正生成器，不放宽检查。早期吞吐探索显示warp和缓存窗口有收益；仍需生产接入及整曲线验证，不能将原语倍率写成生产结果。


## S4生产接入与验收

0.57.13新增固定scalar／coop32配置，默认scalar，独立于seed auto。生产与探针共用s4_warp_reduce.cuh；一warp一系数，共享余数，保留原商估计和有限加回、全源padding和紧凑输出。格式12硬隔离S4成本，NTT表共享，模型增加W+1词组台阶。没有减少MAC／NTT，没有新增显式设备数组或传输。

生产头216次／4523400词GMP、16次空窗口及16次故障拒绝通过。检查发现原合法空窗口仍须校验全部源输入，补为至少一个校验block；探针改为调用生产分派。诊断探针首次使用EcmCudaLaunch的int花括号转换被MSVC拒绝，改为显式dim3，不改算术。失败记录均保留。

四档普通路线完整引擎113.389→94.091s（−17.02%），完整墙钟119.029→98.686s（−17.09%）。首轮八格180.310→159.277s；两档承载出现外层约6%波动，分别追加反序两遍，全部三次中位数几乎持平。最终八格178.389→158.982s（−10.88%），不覆盖首轮或挑最小样本。最高位S4事件15.681→7.939s；完整引擎41.650→34.536s。主矩阵1466条忙碌采样均为1500MHz，功耗上限实读55W。

管理员NCU两版本均固定同一最高位普通输入、seed scalar、skip200取3次。大调用159.308→49.468ms，issue9.205%→68.084%，eligible0.115→1.318warp，local读写归零，寄存器仍40且spill0。不能再把当前瓶颈称为只有减MAC才有效；原语缓存窗口同工作量也有明显收益。更低的新L2命中率对应不同请求集合，不能判成缓存回退。新short-scoreboard及wait依赖仍有优化余地，但不据此宣称shared带宽饱和。

最高位完整诊断的20160叶／5140800词摘要一致；Worker配置、协作S4下28条seed auto、7995／8011回退及相邻旧版默认保护通过。旧0.57.12／新标量的两格分别15.422→15.156s和41.185→40.325s。257项构建输入、46个目标绑定EXE1f14235e…；正式现状、全部身份与限制在performance/STAGE2_S4_REDUCTION.md。仍需其他设备、大B2、容量边界，以及S4 auto／默认资格；当前不作全26格新D选型承诺。
