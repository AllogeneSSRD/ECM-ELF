# 算术位宽区间模型开发草稿

临时开发记录，保留至用户决定处理。正式模型依据与限制见[Auto B2](../architecture/AUTO_B2.md#算术位宽区间预测)，用法见[Stage2](../usage/STAGE2.md)。

## 已确认决策

用户授权默认预测选型：精确配对优先；其他位宽分别预测普通与梅森算术，收益不足或未覆盖NTT/显存边界时保留默认。不再要求新任务具有精确同目标位宽/B2测量；paired开关保留原门禁。B1不作为复用条件。

## 实现

- 索引区分generic和mersenne，以arithmetic_bits取上下区间；target_bits只影响目标侧工作量。原生完整梅森数和承载共用算术资料，保存点整除与校验不放宽。
- WidthPredictor基于当前packing、请求/尾批/giant路线与内存状态计算工作量。基础模型使用20个已有参考点，完整曲线阶段独立缩放，嵌套组件只用作loop权重。
- 用户调优用实测/基础预测的比值校正，各区间只读使用最终摘要；不将预测写成measured。相邻指数可用于启动覆盖判断，省去必然重复的短校准。
- 预测D需要通过其家族的默认D保护，之后才能比较普通/承载。已经证明相对普通默认有收益的精确配对保留优先资格。最终设备free和路线复核仍保留。
- 显式位宽网格默认both：通用可能素数和梅森算术分别调优。后者剥离真因子指数的公共因子与小因子，仅改变合成目标，保持算术指数p；生产save和因子列表不修改。无效或命中因子的合成样本跳过，不记计时。
- 配置只在ecm_options.json维护；新增prediction_policy/tune_arithmetic及CLI帮助，生成参考。模型/参考头文件进入构建源闭包，CUDA对象未改动。

## 冻结参考与限制

内置18条来自全位宽普通/承载矩阵，源EXE50171511…，每条n=1、2400MHz设定；两条来自M12011配对，源EXEf239cb68…、每条n=3、1800MHz设定、无预热。生成工具核对原日志SHA；GPU阶段4/3换算、非负阶段权重和带宽属于估算。源数据没有改写。正式页保留完整身份与计时边界。

初始仅大位宽参考的基础模型在M3877明显高估，因此加入全位宽参考。初始搜索还会仅凭承载整体收益选择小幅估算更优D，因此增加家族内D保护。原始6项查询保留在实验根目录，修正后的查询另存final，不覆盖旧证据。

6项原生只规划：M12011/M12037/M3877，分别使用冻结M12011配对TOML及缺失文件，短校准关闭。M12011保持D240240/p12011；M12037使用跨位宽外推选择D240240/p12037；M3877保留普通。执行曲线0、未新增tune数据，没有GPU性能改善验收。既有M12011 n=3计时不冒充新模型计时。

原证据在`data/experiments/stage2_width_prediction_20261013/`，本机构建为`build_cuda_cmake/stage2_width_prediction_20261013/`；最终构建清单及发布身份与查询日志一起冻结。
