# GUI 生成器 B1 覆盖开发草稿

## 需求

生成器面板提供可选 B1 输入框。留空沿用输入任务中的 B1；填写后统一覆盖本次生成任务的 B1，并在生成预览后才允许追加。现有勾选框与输入框按曲线选项、输出选项分组，标签和控件分列对齐，避免翻译文本或缩放挤压输入宽度。

## 实现

- `src/gui/app.cpp` 的生成器面板收集覆盖值，传入 `GenOptions::set_b1`，修改时使已有预览失效。
- `src/gui/worktodo_gen.cpp` 在去重后应用覆盖值，随后用该值生成和检查 save 文件名。Stage2 工作项自身没有独立的 B1 字段。
- 英文和简体中文界面提供输入框说明；`docs/usage/GUI.md` 描述当前行为。
- `src/gui/app.cpp` 使用两列表格排布选项，每个控件单独一行，输入文件与目标路径另起一行显示；修改选项会使已有预览失效。
