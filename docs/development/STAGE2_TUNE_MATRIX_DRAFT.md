# Stage2 紧凑矩阵开发草稿

授权范围：同参数重复测量合并 repeats 与平均时间；不同参数保留多行；以程序版本代替二进制 SHA；保留 matrix 列对齐；不兼容旧格式；表外只保存确定性条件。

设计：格式 8，每个位宽一个 matrix，NTT 每个条件一个 matrix。条件包含程序版本。均值、样本标准差和次数采用可合并统计，波动保护不再使用 MAD。用于预测的互斥阶段均值保留，重复检查计数及预测过程保留在内部 JSONL，TOML 使用已验证标记。运行观察仍按参数限制累计次数，不限制正常参数组合的保留。

聚合必须保留有界的测量身份，避免恢复结果和重复合并增加 repeats。同一统计快照的子集忽略，超集替换；部分重叠、无法精确还原的快照拒绝合并，提示从原始 JSONL 去重恢复。

实现与验证完成，版本0.37.1。每行采样上限包含B1，跨B1的成本复用仍合并统计；同版本重新编译可复用，不同版本缓存重新生成，不改变队列身份。

CPU门禁验证独立两遍均值/方差、较慢观察、默认10次上限、不同B1行、版本隔离、部分重叠拒绝、NTT布尔参数及读写稳定性。旧格式明确拒绝，不进行无依据迁移。

GPU1 4060 Laptop：生产队列15次NF，12次观察合并为2行（10+2）；11次实测选型经回执独立核对，GMP抽查18836、错误0；只读、显式锁定、Mont Auto B2及因子命中排除通过。正式调优与规划22项门禁通过；恢复12次观察的重复导入/合并保持次数、均值与标准差，坏回执拒绝；4行NTT排序及格式化幂等通过。这些是功能检查，不提供性能提升结论。

调试记录：正式NTT读回暴露布尔列不能用纯整数解析，已加入专用选项解码及回归。旧portable GPU测试把selected标记误当作锚点复用证明，并未关闭新增运行试跑，还假定网格只有一个算术家族；已按实际模型、耗时、规划、候选数及无副作用检查修正，未放宽算术门限。失败目录保留。
