# Giant auto 与小B2全位宽验证草稿

目标是让giant支持auto／scalar／coop16／coop32，使用实际执行后端作为tune身份；自动请求不进入测量身份。无合格对照保持标量，显式请求和旧环境覆盖保留。

先在当前有效D／布局／链长上完成baby及有限giant对照，再继续D和链长搜索；不展开D×baby×giant全网格。低位、不走chain、预算回退不启动协作候选。参考必须来自当前条件的合格测量，完整比较包含点启动检查；不能只凭另一个D的未配对快速观察启用协作。

验证复用13位宽、普通／承载26格、名义小B2=26000000000的冻结输入与优选D／布局／链长。用户指定最终各格只独立复测1次，明显回退再补测；训练样本与最终成绩分开，原始样本保留。新曲线表达最佳已验证选型的独立结果，不取学习期的单次最小时间。设备设置不由脚本修改，按实际遥测说明可比较范围。

原始证据计划放`data/experiments/stage2_giant_auto_20261101/`，汇总和图分别放`data/benchmarks/`、`data/figures/`。GPU0有外部负载，先仅使用空闲GPU1 RTX4060 Laptop。完成后更新权威选型与性能文档，保留此草稿待用户处理。

## 实现与门禁

版本0.57.9，两项默认auto。Giant按当前算术与独立链数区域复用配对；实际模式仍为0／16／32，未增加tune格式版本。运行时逐项比较，显式ECM tune在首个有效区域最多完成四组主要对照，相邻D只测胜者。手动后端和既有环境优先级保留。

真实测试发现两个边界并已修复：最终凑整重建形状会丢掉已选giant后端；显式小P虽然可生成候选，却被采样门槛阻止入账。前者在实际B2准入前保留请求，后者允许固定D的精确观察，自动D搜索的P≥512限制不变。

CPU后端统计／资格、既有runtime搜索、B2边界、533项TOML布尔别名及GUI配置保存／覆盖通过。`gpu_auto05`通过固定和凑整B2的10曲线学习、只读复用、小P八曲线、未配对保护；`gpu_formal`通过首D配对、邻D只测胜者、重复运行不重测。前期测试与失败输出原样保留，不进入性能成绩。

最终Stage2 SHA256 `fb39b41e0edeaa9b85ad1df876d6bb810c1fd83f6bb351e14247796dc9c2bf61`，256项源码摘要已核对，4个CUDA目标文件与0.57.8逐字节相同。GUI SHA256 `3345306a8dc37c9b9328965b7bd73a9f7450c534b02feb6e65189d2b6d9f9556`。仅改变配置／选型／采样，没有更换设备算术。证据`binary_audit.json`。

## 全矩阵

`matrix01`于2026-11-02完成全部26格：100次训练、60次独立调用，160次NF通过离线重读；两格回退补测保留首轮。当前同二进制引擎合计366.518→299.939s（−18.17%），曲线墙钟384.654→318.633s（−17.16%），无残留双门限回退。8个高位格均选baby32／giant32；18个低位格仍标量。全部忙碌频率采样12045条中7条低于1500MHz，未丢弃。

13个主曲线点由训练成绩选择算术家族，独立n=1合计115.191s。仅对后端做有限学习，D／布局／链长来自冻结旧优选项，不能称为重新穷举全局D或全部后端组合。训练引擎1993.403s不计入成绩。正式结论、阶段图及证据指引已写入[Stage2性能](../performance/STAGE2.md)。原始失败样本和此草稿均保留，待用户决定草稿处理。
