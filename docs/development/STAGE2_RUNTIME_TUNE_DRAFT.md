# Stage2 模型比值与运行采集草稿

## 目标与实现

用户要求ECM矩阵增加实测/模型时间比值，并让正常计算补充缺失位宽数据。实现采用`measured_model_ratio=median_seconds/predicted_seconds`，引擎init+main计时边界；记录`prediction_model`和`prediction_basis`。新调优与新运行在测量前冻结预测。旧摘要下一次发布时排除自身重建留一预测，不新增独立验证计数、不改旧计时和误差。

默认`stage2_tune_runtime=true`，可由INI或CLI关闭。生产曲线仅在当前算术位宽及NTT/驻留/giant执行区间缺实测时采集，普通与梅森独立索引，不以B1为门槛。只接受P≥512、完整多批拓扑、clean且无因子的已核验完整结果，计划/实际路径不一致时跳过。

运行单曲线用runtime_save身份，与正式重复调优分开维护，避免最快单次观测阻止较慢但合格的正式参考。运行摘要用于区间校正及调优预测，不提供精确配对资格；保留工程误差余量。覆盖后不继续记录每条曲线。

结果先持久保存，之后尝试既有独占锁下的重新读取和原子发布；缓存失败不导致曲线失败。结果中保存结构化条件、摘要和预先预测。复用导入工具新增runtime-results入口，离线生成中间格式7文件，再交原生merge发布；旧缺结构结果不自动推断。全位宽、普通/承载和短NTT基准关闭运行采集，维持冻结比较。
