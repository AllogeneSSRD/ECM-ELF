# 小B2全位宽布局与tune验证草稿

## 范围与协议

用户要求先完成较小B2并分析，再决定后续；不继续较大B2矩阵。输入沿用13份精确Edwards余因子Stage1点，实际N318–16272 bits，B1=50000，两种归约。名义B2=26000000000，实际采用原Prime95校准后的27015978990或27567389850。

构建为0.54.7，SHA256 `be599bb90aeba1417be92f4096886a2722a2039d83a983508496134ac4d6e636`。GPU1 RTX4060 Laptop，55W设备上限、实际频率记录在NVML；不写显卡设置。GPU0有外部任务，不参与测试。CPU频率不由本测试固定或归一化。

用户批准复用旧tune及独立复测，仅允许Codex界面PID16148及其冻结程序路径绕过外部上下文门禁。其他外部GPU进程仍拒绝。原门禁拒绝两次界面上下文，失败证据留在`default_screen/`、`default_screen2/`，不纳入计时。

默认自动布局筛查26格，各n=1。普通首轮合计260.037714 s，承载161.792141 s；旧0.38.4低档n=3中位数之和分别259.601701、161.462243 s。短耗时明显回退三格已各补2遍，保留首轮，改用中位数后的普通合计259.987610 s、承载161.792141 s；整体基本持平，不作所有单项不回退结论。

旧0.39.3性能文件仅作先验，不重标记条件、布局或时间。每个位宽先重测旧最快合格几何的当前自动布局2次，再解锁全部参数，继续正常48条worktodo计划队列；本次学习实际限制共8次完整调用，原生停止允许至多1条已经开始的额外调用。全部学习结束后冻结profile，各格另测3条，关闭写回；仅这39条新调用作为本轮tune主成绩，不把学习数据混入独立均值。不声称搜索穷尽。

## 计时与图表

主边界是`stage2_full_wall.total=init+main`，规划单列，不把日志`shape`再次加到总量。Baby从init拆出，剩余init为F树及初始化余项；main中求逆、giant点、G树、fold、下降、累乘/GCD分别记账，其余为闭合残差。NTT/S4嵌套计时不重复相加。百分比为逐调用占比的均值；另以曲线墙钟展示选择核心及外层余项，不声称恢复未记录的读取/收尾独立时间。

原始证据位于`data/experiments/stage2_layout_matrix_20261031/`。`default_screen3/`保存26格默认筛查；按用户范围边界停止排程时，一条已启动的高B2进程自然结束，原始日志留存，不纳入小B2矩阵。`low_warm2/`保存完整小B2默认子集的严格审计、旧tune副本、构建身份、有界学习和独立复测。首次单档审计测试的失败目录保留。

入口：`bench_stage2_layout_matrix.py`、`rescreen_stage2_matrix.py`；绘图从`plot_stage2_version.py --layout-study`进入。已有双档审计保持默认要求，单档必须明确声明范围，不能将半矩阵标为双档通过。

## 完成结果与后续候选

独立tune均值之和148.447070 s，相对旧学习期149.707984 s为−0.84%，相对本轮较快默认事后参考161.171005 s为−7.89%。同二进制固定D的14格旧布局93.584335 s、自动91.219053 s，G树24.638000→22.070333 s；14格根摘要均为正且匹配。旧布局仅n=1，不作为全矩阵n=3因果证明。默认318-bit承载补测后仍较旧中位数慢5.94%，保留此结果。

当前-only阶段图从main余项拆出Giant叶准备／同步；旧日志缺细项，另画共同口径图。7995-bit默认点块138240＋11700，尾块退ladder；tune后130212点单块走chain。固定D的尾块重平衡、算法阈值与D成本模型修正仅是下一步候选，未在本轮实现。大档B2按用户要求暂停扩展，先报告本档结论。

补测工具已修正未来记录的started_utc，并强制要求正的根摘要；已有rescreens／legacy_controls元数据从源样本继承了started_utc，不将该字段用于补测起点或耗时。原始证据不改写；补测发生时间以各自遥测／日志为准，主成绩始终来自引擎原始闭合计时。
