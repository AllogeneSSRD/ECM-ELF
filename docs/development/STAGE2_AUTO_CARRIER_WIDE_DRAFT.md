本文件为临时开发草稿。完成后由用户决定如何处理；正式行为维护在 `docs/architecture/AUTO_B2.md`，正式性能证据维护在 `docs/performance/STAGE2.md`。

## 实现与实验范围

- `stage2_auto_carrier=1`：标准梅森 worktodo 的指数用于候选推断；保存点与重建 N 核对、N 整除 M 验证、当前显存准入和默认性能保护继续有效。
- CLI `--auto-carrier 0|1` 覆盖 INI；显式 `--carrier-exponent` 锁定算术优先。
- 开关通过曲线子进程传递，纳入队列恢复身份；短校准按最终候选范围判断缺失覆盖。
- 新 HTML 为 `.refactor/Mersenne_exponent_factor_10000-19999.html`。从文件中剥离所有列出的已知因子及其重复幂，选实际位宽不超过目标档且最接近的余因子。
- 档位 10240/12288/14336/16384 对应 p=10267/12511/14401/16319，实际 N=10232/12285/14328/16272 bits。当前承载指数上限 16384，最高档并非精确 16384-bit 测量。
- 四个新点 B1=20、sigma=26，Python 与 GMP-ECM 独立生成 X 完全一致；复用原九个低位宽保存点及校验身份，不修改维护中的数据库。
- 预算 arena6300/fold640/batch256 MiB；B2=2.6×10⁷、2.6×10⁸，每条路径每格一条正式曲线，热身和训练独立保存。
- 训练只考虑普通/承载两路径各自的默认 D，不做完整候选表扫描。训练结束后冻结同一 TOML，比较显式普通、显式承载、worktodo 自动候选三个入口。
- 设备只读采样，不改频率、功耗或驱动。原始数据在 `data/experiments/stage2_auto_carrier_wide_20261012/`。

## 第一轮观察与补齐条件

B2=2.6×10⁷ 的默认 D=16170、P=1680、G=1，超出当前 tune 多批完整 fold 的采样合同。保留固定路径计时和自动回退观察，不能伪造缺失的校准摘要。

B2=2.6×10⁸ 的高位宽训练需要增加独立预算以补齐承载。25秒为软预算，完成当前测量再停；第一轮 12285/14328/16272-bit 只有普通基线。缺失时自动路径须回退普通。

初次配置门禁与高位宽训练曾短暂重叠；第一轮相关训练不作为独立性能结论。后续串行门禁、补齐和持出计时分别留存，不覆盖第一轮证据。
