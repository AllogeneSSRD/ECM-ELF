# Tune 预热开关与真实任务配对草稿

临时开发草稿，保留至用户决定处理。正式说明在 [Auto B2/tune](../architecture/AUTO_B2.md)及[Stage2使用](../usage/STAGE2.md)。

## 已确认要求

- ECM/NTT tune默认无预热，显式开关才增加一轮；启动短校准采用相同策略。
- 默认自动承载以真实worktodo/save为输入，不为通用随机模数猜测承载指数。
- 普通与承载优先补默认D参考，之后各自搜索NTT区间与D邻域。
- 保留现有同位宽/B2/执行形状配对性能保护、算术检查、显存准入和最快正式中位数更新规则。

## 实现范围

- `stage2_tune_warmup=false`，CLI `--tune-warmup 0|1`优先；各测量循环默认从正式repeat=1开始，显式预热使用repeat=0且不进入统计。
- 新测ECM/NTT摘要记录`warmup_runs`；保持格式7，旧摘要不补造来源。setup/warmup/verification秒数继续不进入NTT性能TOML。
- `--tune ecm`优先读取配置队列，`--tune-worktodo FILE`明确指定队列，`--tune-exponents`保持通用网格入口。真实任务采用生产B2；命令行列表可覆盖。
- 只读取当前worker和skip后的首个有效save，重建N并检查匹配；自动承载验证整除。相同位宽的不同真实输入有独立调优对象，不能用位宽键覆盖输入。
- `--tune-save`可从匹配任务取得指数；显式指数优先。完整M_p已由普通路径执行梅森归约，自动模式不重复同一算术。
- 新任务的配对参考优先于NTT组件与D邻域；预算截止保留已完成正式样本，不推进队列。
- 本轮正式配对参考按目标对象及完整Shape复用；文件保留更快旧部分摘要时，不重复本轮已完成的测量，不补造旧重复数。
- 只冻结选中的一条原始save记录及任务来源，保留checksum和数值；不复制整个大save，不覆盖用户输入。B2网格中过小的档位过滤，剩余为空时提示输入问题。
- 更新配置生成物、CLI帮助、正式说明；新的生产编译输出在`build_cuda_cmake/stage2_tune_task_pair_20261012/`。
