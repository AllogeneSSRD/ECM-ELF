# 本地群阶与点阶分析可行性草稿

研究日期：2026-10-23。范围：评估现有 PARI/GP 调用能否由本地算法替代，包含隔离原型验证；尚未接入生产路径，不改变版本号、配置或数据库。此文件为临时研究草稿，后续实施时继续维护，完成后提示用户处理。

CPU/GMP 独立模块已进入实施验证；当前接口、算法、预算和证明限制统一见[正式模块说明](../architecture/GROUP_ORDER.md)。以下研究过程保留为草稿证据，不作为新增生产能力的声明。

## 结论

可以自行实现，但必须区分三个任务：计算曲线群阶 `#E(F_p)`、分解已知整数群阶、计算当前初始点的精确阶 `ord(P)`。其中大素域的完整群阶计数最难。实现 Pollard rho 不能单独取代现有 GP 流程。

建议先做 CPU/GMP 的有界整数分解和精确点阶模块，再做有资源上限的小素域 BSGS；38～49 位十进制素域的完整群阶暂时保留现有后端。若要求在这些输入上也完全摆脱 PARI，则需独立推进 Schoof/SEA 计数与素性证明，工作规模明显大于一次诊断功能改造。

对已成功的 ECM 曲线存在另一条实用路线：利用实际 Stage1 标量及可恢复的 Stage2 剩余点阶，直接恢复原始点阶，从而给出 B1/B2 数学界限。它可以省掉完整群阶计数，但不产出完整群阶，也不解决任意 sigma 扫描。

## 已确认的仓库现状

- `src/ecm/application/cli/group_order.cpp`：`compute_group_order_pari` 重建 Montgomery 参数化 0/1/2/3 的 Weierstrass 模型，启动 GP，执行 `ellcard` 与 `factor`。`print_group_order_factor` 用返回的群阶分解生成诊断输出，没有计算点阶。CLI 路径的 sigma 是 uint32，不能因此将新公共接口限于 uint32。
- `src/ecm/application/cli/ecm_driver.cpp`：`--go` 提前检查 GP；GPU Edwards 不允许此选项。它不是现有 Edwards 群阶计算入口。
- `tools/ecm_dataset/param0_order.gp`：证明模数素性、构造 PARAM0 模型和原始基点，再计算群阶、完整分解、点阶、点阶分解，并以 `isprime` 和标量乘检查结果。
- `tools/ecm_dataset/edwards_order.gp`：完整 uint64 sigma 的 Atkin–Morain 构造、保留正确二次扭曲的模型映射，再计算并验证群阶和点阶。`edwards_order.py` 输出独立证据，不写 PARAM0 数据库。

- `src/ecm/service/stage2/ecm_stage2_factorize.h`：另有 GP 整数因子再分解调用。它不涉及曲线计数，可以成为以后共享整数分解服务的消费者。
- 已有 GMP 多精度算术与曲线构造；独立 CPU Edwards Stage2 的 `ecm_cpu_stage2_main.cpp` 使用外部 libecm 的 `ecm_factor`。这不表示所有主程序目标已经链接了通用整数分解器。不能只凭本地 `ecm.h` 的声明就当作已有完整实现。

### 必须保持的数学口径

构造身份是曲线族、Montgomery param（仅 Montgomery 使用）与 sigma；有限域分析还必须包含素数 p。算法和执行后端可以不同，输出对象必须一致。Edwards 映射到 Montgomery/Weierstrass 只是内部表示，不能改用同 sigma 的另一条 Montgomery 参数曲线。

对 `B y² = x³ + A x² + x`，保留 B 后可映射为 `Y² = X³ + BA X² + B²X`，其中 `X=Bx, Y=B²y`。随意令 B=1 可能切换到二次扭曲，改变群阶；这一点比更换计数算法更先需要保证。

群阶只给出点阶的倍数，不能一般性地视作初始点阶。当前 `--go` 的 `go_min_bounds` 由群阶生成，不应当成为新模块“精确最小界限”的定义。`largest_prime` 的当前实现还按最大素数幂选择条目；如果某个小素数的幂更大，该字段不一定代表最大素因子。本研究不修改这条已有输出，迁移时需单独设计兼容行为并补充反例验证。

实际 Stage1 标量必须从执行计划获得。例如标准 LCM、choose12、Edwards 的 48LCM 不能混用。对初始额外标量 c，应先取有效点阶 `ord(P)/gcd(ord(P),c)`；标准 LCM 的界限需要覆盖素数幂，标准单素数 Stage2 仅补上一份剩余素数。数学可消去条件也不保证在复合输入上一定提取到该真因子：还需考虑 gcd=N、其他因子同时消去、实现范围等。

## 可选算法与适用边界

### 1. 已知整数群阶的分解

可以先实现试除、完全幂检测、Pollard–Brent rho、递归拆分和素性分类。rho 适合提取较小素因子，其启发工作量取决于最小待提取素因子的平方根，而不是原整数总长度。较难余因子可再接 p−1、已有 ECM 能力；若目标是覆盖普通通用整数分解，还需要考虑 QS/MPQS 等后端。PARI 的 `factor` 已是一套算法组合，而不是单个 rho。[PARI 整数算术手册](https://pari.math.u-bordeaux.fr/dochtml/html/Arithmetic_functions.html)

第一阶段应返回素因子、未分解余因子、素性级别及停止原因。预算耗尽必须保留余因子；不能将乘积正确但余因子未证素的结果标为完整素因子分解。

`mpz_probab_prime_p` 返回 1 表示 probable prime，不能代替数据集当前 `isprime` 的证明要求。[GMP 手册](https://gmplib.org/manual/Number-Theoretic-Functions) 小整数可使用有明确范围证明的确定性检验；大整数需 Pocklington 等证书方法或继续调用现有证明后端。Pocklington 的可用性取决于 p−1 的已知分解，不能保证覆盖全部输入；完全独立时还要规划更通用的证明方案。

### 2. 已知群阶或已知消去倍数时的精确点阶

若已知 `M P = O` 且 M 已完整分解，逐个尝试移除其素因子 q：只在 `(M/q)P=O` 时令 `M←M/q`。结束后检查 `MP=O`，并对最终每个不同素因子 q 检查 `(M/q)P≠O`，即可证明 M 为精确点阶。条件是模数确为素数、曲线和点合法、M 的素因子完整且素性等级明确。

这部分只需已有多精度域运算、可靠群运算和标量乘，不需要 SEA。应作为统一点阶服务，而不是继续写在 CLI 的打印代码中。[MIT 椭圆曲线课程习题及算法](https://math.mit.edu/classes/18.783/2017/ProblemSet4.pdf)

### 3. 小素域完整计数：枚举与 BSGS/Mestre

枚举 x 并求右端的 Legendre 符号，加上无穷远点，适合小域及独立验证。主程序的较小因子可考虑 Hasse 区间 BSGS：群阶位于 `p+1±floor(sqrt(4p))`，区间宽度约 `4sqrt(p)`，平衡 baby/giant 搜索需要约 `2p^(1/4)` 个表项及同阶点运算。

这是指数于 p 的 bit 数的算法。按 p 约为 `10^20、10^30、10^40、10^50` 估算，baby 表项约为 `2×10^5、6.3×10^7、2×10^10、6.3×10^12`。这些是公式估算，不是计时结果，未计入哈希表、对象与坐标内存开销，不能据此宣称已有某个位数的实用支持。

单个随机点的一次 `nP=O` 不证明 n 是完整群阶。隔离原型遍历整个 Hasse 区间，只在唯一消去倍数时返回群阶，其余明确拒绝。完整后端还应加入随机点累积精确点阶、二次扭曲的 Mestre 方法、小域枚举和内存/时间预算；否则低阶点、非循环群会造成停滞。[Sage 的 BSGS/Mestre 算法说明](https://doc.sagemath.org/html/en/reference/arithmetic_curves/sage/schemes/elliptic_curves/cardinality.html)

### 4. 较大素域完整计数：Schoof / SEA

对现有 124～163 bit Edwards 样本，完整计数应采用 Schoof/SEA 这类方法。基本路线是计算 Frobenius trace 在若干小素数下的约束，通过 CRT 与 Hasse 界恢复 trace，再取 `#E=p+1−trace`。需要有限域多项式算术、除法多项式或模多项式、Frobenius 运算、Elkies/Atkin 分支及特殊 j/超奇异等情形处理；现有整数模 p 的 Stage1/Stage2 NTT 不等于已具备这些部件。[Schoof 1995 原文 §§5–8](https://numdam.org/item/JTNB_1995__7_1_219_0.pdf)

可以自行写，但这应独立立项。即使完成 SEA，群阶的整数分解和大素数证明仍是不同的后续任务。固定挠子结构能提供约束和常数优化，不能把任意 sigma 的群阶变成简单闭式。

### 5. 已成功 ECM 曲线：绕过完整群阶的点阶恢复

Stage1 命中素因子 p 时，重建原始点并确认 `[M]P=O`，其中 M 是实际执行的已知标量。对 M 的已知因子使用精确点阶剥离法，就能恢复点阶，无需知道 `#E`。

标准单素数 Stage2 命中时，可以先计算 `R=[M]P`，再在可控界限内恢复 R 的阶 q。最简单的区间 BSGS 的表规模约为 `sqrt(B2)`，与 p 的大小不直接相关；但每次群运算成本仍随 p 增长。确认 q 后，先检查 `[q]R=O`，再以 Mq 为原始点阶的已知倍数并剥离。若 q 未证明为素数，必须先完整分解 q；发现任意消去倍数也必须继续取精确阶。

此路线的先决条件是有成功因子、可重建的正确原始点、精确执行标量以及可管理的剩余阶范围。它不适用于尚未成功的任意 sigma；当前实现的 relocation、实际命中范围、特殊消去和保存点语义必须逐项核对，不能只由日志 B2 假定全部成立。对一般情况，返回不适用或未完成。

### 6. 进程内 libpari：降低集成成本的独立选项

如果诉求仅是取消 `gp.exe` 子进程，可以研究直接链接 libpari，继续调用其计数/分解/证明能力。当前安装已有 `libpari.dll`，不代表仓库已有开发头文件、兼容导入库及生命周期封装。需要验证栈管理、错误捕获、线程隔离和打包依赖。

这能保留算法覆盖面，但仍依赖 PARI，不属于自行实现算法。先让 GP 常驻或批量执行同样只解决调用开销；本研究未测量调用开销，不能宣称具体加速。

## 隔离原型与验证结果

原型：`data/experiments/local_group_order_20261023/probe.py`，Python 3.14.7 标准库，使用仿射 Weierstrass 群运算、完整区间 BSGS、试除与 Pollard–Brent rho、点阶剥离。未链接生产程序、未调用生产曲线运算、未写工作数据库。大整数 Miller–Rabin 只作为筛选，所有 Edwards 最终因子额外经 GP `isprime` 核验，所以这不是已完成的本地素性证明器。

验证内容：

- 三个 PARAM0 样例 p=`1000003、1000000007、59649589127497217`，本地完整区间 BSGS 的群阶逐一与 GP `ellcard` 匹配。
- 17 位样例 p=`59649589127497217`、sigma=26：独立返回群阶 `59649589504338456 = 2³·3·7·67·233·331·599·114713`；原始点阶为 `14912397376084614`，即群阶的四分之一。baby 和 giant 各 31256 步，Hasse 区间只有一个消去倍数。
- 同样例仅输入 p、sigma、B1=599、B2=114713，采用无额外挠子乘数的标准 LCM：残余点阶搜索的 baby 和 giant 各 339 步，恢复 q=114713，再从 Mq 恢复同一原始点阶，全程不使用完整群阶。该步骤数比较不是总运行时间比较，未计入 LCM 标量乘和点阶剥离。
- 17 组 Edwards 直接输入已知参考群阶，本地整数分解全部与冻结参考一致；使用冻结参考的正确模型和初始点，17 组点阶及其最小性全部复现。没有在这些大域上运行本地完整群阶计数，也没有在本原型内独立重建 Edwards 构造。
- 24 组小素域 PARAM0 输入经过逐点计数核对；BSGS 对 7 组返回正确唯一群阶，对 17 组因低阶点或区间多解明确拒绝。另检查二阶点拒绝、重复素数幂与复合数递归拆分。本原型没有完整 Mestre 补全逻辑，不能据此声称小域输入全部支持。

## 建议实施顺序及验收条件

1. **公共数据模型与整数分解**：新服务接收 p、曲线族、可选 param、完整 uint64 sigma，以及显式计算目标和预算；整数分解服务独立于曲线计数。结果区分完整/部分/超时/不支持、群阶与点阶、proven 与 probable，且保留未分解余因子。
2. **点阶及成功曲线诊断**：先复用可信曲线构造，支持从已知群阶或已知消去倍数恢复点阶。覆盖 LCM/choose12/48LCM，给出单素数 Stage2 前沿。精确界限必须以点阶和实际标量为依据；旧 CLI 输出单独处理兼容性。
3. **小域计数**：枚举提供独立 oracle；加入 BSGS/Mestre、二次扭曲和资源上限，达到全部返回结果可认证、所有歧义明确退出。按实测域大小与结构划分覆盖范围，不按“20 位一定可用”写死承诺。
4. **大域策略**：保留现有 GP 作参考和回退；如需取消子进程，先验证 libpari 集成。如需完全自行实现，则进入 Schoof/SEA、多项式层和素性证明项目。

验收至少包括 Montgomery param 0/1/2/3、Edwards uint64 sigma、高阶与低阶点、非循环群、素数幂、错误扭曲、退化曲线、复合模数、分解超时及素性未证状态；对有正确定义的结果检查群阶 Hasse 界、分解乘积、点阶整除关系和逐素因子最小性。只检查 Hasse 界与随机点消去不足以证明任意候选群阶正确。最后再用生产 Stage1/Stage2 验证边界样例，保留前沿正反对照。

尚待验证：C++/GMP 下的 BSGS 内存与吞吐边界、成功 Stage2 点阶恢复对实际 relocation/命中范围的适用性、较大 B1 下已知倍数剥离的成本、整数分解预算分布和素性证明覆盖率、libpari 在当前 Windows 工具链下的可集成性。未验证项不作为当前产品能力。
